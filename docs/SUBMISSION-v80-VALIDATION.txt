공무담 v80 · 새 설치 검증 결과
확인일: 2026-10-27

반영 내용
업무자료 정리를 프로젝트 만들기 → 폴더·파일 추가 → 질문 흐름으로 간소화했다.
자료와 대화를 한 화면에 두고, 읽기 작업·다시 읽기·업로드·기존 자료함 연결은 자료 관리에 모았다.
답변 방식·확인 범위는 펼쳐보되 근거와 읽지 못한 부분을 보존한다.
이번 ZIP에는 이전 v79 이후의 결론 우선 답변, 검토된 물품관리 자료, 실무 답변 검토 기능도 현재 코드 그대로 포함한다.
개인 DB를 내보내지 않고 검토된 공통 배포 자료 123건(발췌 117건, e-사람 PDF 6개·221쪽)만 포함한다.
모델 가중치·개인 소속·프로젝트·대화·기관 비공개 원문·사용 설정은 제외한다.
합성 교육 예제 세 파일과 새 PC용 실행 안내, 재현용 검증 도구를 동봉한다.

새 설치 확인
후보 ZIP 전체를 같은 Windows PC의 한글·공백 포함 새 폴더에 풀었다.
install.bat으로 새 venv를 만들고 동봉 wheel 24개에서 --no-index 설치했다.
pip check 통과, 공통 자료 123건 복원, 실제 설치 폴더 안 원문 경로 확인.
tools/run_local_app.py --port 8899 --no-browser로 별도 실행했다.
실제 사용하는 8787 DB나 모델 설정을 제출 데이터로 사용하지 않았다.

AI 없는 실제 질문과 근거
verify_notebook_submission.py에서 합성 프로젝트를 만들고 폴더 1개와 개별 파일 1개를 연결해 총 3파일을 읽었다.
미회신 부서, 핵심 요약, 일정과 할 일, 자료 비교, 보고서 초안의 5질문 모두 offline 모드에서 근거를 반환했다.
미회신 질문은 회계과와 회신 현황.txt 3행을 반환했다.
답변의 모든 인용에서 원문 위치의 텍스트 일치와 원본 파일 SHA-256을 검사했다.
자료에 없는 항공권 취소 수수료 질문은 근거 부족으로 응답했다.
초안 수정 저장·프로젝트 재조회 후 대화 보존·원본 파일 불변을 확인했다.
B안 실제 화면에서도 질문 전송 → 회계과 답변을 확인했다. Windows 폴더 선택창 열림과 취소도 확인했다.
공문·기존 업무 23질문 및 공식 조문 10개 원문/메타데이터/해시 검사를 추가 통과했다.
기존 가족돌봄·건강검진·공용차량·사무용품 예산·개인정보·기록물·e-사람 질문이 포함된다.
이 검사들에서 실제 AI 모델 호출은 0회다.

자동검사
새 설치본에서 프로젝트 17, 본문 추출 11, 요약·일정·비교·초안 13,
네이티브 선택창 7, 자료 연결 4, 패키지·통합·실행 Python 20, 데스크톱 Node 36:
총 108개 통과. 전체 서비스 테스트를 이번에 모두 재실행한 수치는 아니다.
기존 프로젝트 격리·읽기 취소·실패·후반부 색인과 출처 검사는 해당 테스트 범위에 포함된다.
Graphify 영향 조회 후 refresh 실행: 관리 대상 212파일의 지도는 이미 최신이며 재생성할 변경은 없었다.
이번 변경의 패키징 도구·문서는 현재 코드 지도 관리 범위 밖이므로 직접 검토와 패키지 테스트로 확인했다.

실사용 페이지 연결
점검 중 개인용 8787 서버가 중지되어 있음을 확인해 같은 서비스 루트로 다시 시작했다.
현재 B안 페이지에서 기존 합성 프로젝트의 3자료·대화를 유지한 채 새 질문과 AI 없는 답변을 확인했다.
새 설치 검증용 8899와 실제 사용하는 8787은 별도 데이터이며, 검증용 프로젝트를 실사용 DB로 복사하지 않았다.

한계와 미완료 검사
다른 물리 PC에서 실행한 결과가 아니라 같은 PC의 새 폴더·새 venv·새 DB 설치 시험이다.
별도 검증 서버 종료·재시작 명령은 자동 승인 검토에서 차단되어 실제 서버 재시작 비교는 하지 않았다.
프로젝트 재조회와 기존 복구·지속성 테스트는 통과했으나 서버 재시작 실증을 대체했다고 주장하지 않는다.
Gemma·Llama 실구동 재시험은 이번 범위에서 하지 않았다. 동봉 v71 모델 기록은 과거 결과다.
법령 현행성이나 여비 계산 가능 기간을 새로 승인·갱신하지 않았다.
