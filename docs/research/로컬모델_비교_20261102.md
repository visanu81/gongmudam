# 솔라(solar-pro4) ↔ Qwen 3.5 9B 비교 (2026-11-02)

## 결론
- 공무담 답변에서 두 모델의 차이는 작다. 85문항 중 같은 조문을 고른 경우가 대부분이고, 다른 경우는 조문 안에서 어느 줄을 강조하느냐 정도다.
- 질문에 딱 맞는 줄을 고르는 정확도는 솔라가 조금 낫다. 속도는 모델이 올라와 있으면 Qwen이 빠르다(첫 호출만 약 15초).
- 답변 본문은 어느 모델이든 검색된 원문 조문 전체를 보여준다. 모델은 후보 원문 가운데 하나를 고르기만 하므로, 모델을 바꿔도 근거 조문 자체는 거의 바뀌지 않는다.

## 시험 방법
- 질문: service/reference_data/service_rules_checks.json 85개(공개 법령·조례 평가 질문). 개인 자료 없음.
- 검색은 AI 없이 같은 결과를 쓰고, 공무담이 AI를 부르는 단계(_model_evidence: 후보 최대 8개 중 하나 고르기)만 모델별로 실행.
- 솔라: config의 upstage 프로필(solar-pro4, reasoning_effort none).
- Qwen: 새 RTX PC Ollama(http://100.88.175.64:11434/v1, Tailscale), qwen3.5:9b Q4_K_M, reasoning_effort none.
  생각 모드를 켜 두면 답 대신 생각만 하다 토큰을 다 써서 빈 응답이 나온다. 반드시 꺼야 한다.
- 스크립트: tools/compare_quote_models.py, 결과: docs/evidence/model-compare-20261102/.

## 적용할 때 주의
- 현재 공무담은 답변용 AI를 업스테이지 또는 이 PC(127.0.0.1)의 모델만 쓴다(knowledge.answer의 주소 검사). 다른 PC의 Ollama 주소를 넣으면 답변에서 AI를 쓰지 않고 원문 검색으로 안내한다.
  RTX PC 모델을 쓰려면 공무담을 RTX PC에서 실행하거나, Tailscale 주소를 허용하도록 바꿔야 한다(별도 결정 필요).
- RTX PC에 받은 모델 중 abliterated·uncensored 판은 안전 거절을 지운 변형이라 업무용 기본값으로 권하지 않는다. 시험은 기본 qwen3.5:9b로 했다.
- 업무자료 정리는 아래에서 따로 비교했다. 업무 묶음 자동 분류(folder_ai의 긴 JSON 작성)는 지금 3단 화면에서 쓰지 않아 비교하지 않았다.

## 검색 수정 후 (같은 날)
- 고친 것(업무자료 정리 검색, folder_projects·project_query·project_tasks):

  - "질문 낱말 2개 이상 일치" 조건을 없애고, 드물게 나오는 낱말일수록 높은 점수(문서 빈도 역수)를 주어 가장 좋은 결과의 절반 이상만 남긴다.
  - 묻는 항목 낱말(일정·총액·항목 등)이 아닌 주제 낱말이 들어 있어야 한다. "체육대회 일정"이 다른 일정을 모두 끌어오지 않게 하려는 것.
  - 파일마다 후보 8개까지만 두어 큰 문서가 후보를 독차지하지 못하게 했다.
  - "A와 B를 비교": 한 파일에 모든 낱말이 없으면 주제별로 가장 맞는 파일(파일 이름에 주제가 있는 것 우선)을 하나씩 고른다.
  - 업스테이지처럼 OpenAI 방식 서버에는 근거 선택 JSON 형식을 함께 보낸다. 솔라가 비교 질문에 문장으로 답해 실패하던 문제.

## Laya 분류 모델 시험 (같은 날)
- 대상: RTX PC의 laya-serve(http://100.88.175.64:18080/v1/systemone, Tailscale), 모델 local_ml(경로상 laya-multilingual), CPU 실행.
  요청 형식: {"model":"local_ml","state":{"document":질문},"questions":{"topic":{"type":"choice","instructions":…,"criteria":{라벨:설명}}}}.
  model을 빼면 "inference failed"(500)가 난다.
- 방법: 평가 질문 85개를 공무담 규칙 분류와 같은 7개 분야(휴가·보수수당·초과근무·여비·당직·징계·복무 일반)로 분류시켜 비교.
  규칙 분류는 85개 답변 검증을 모두 통과하는 기준이다. 결과: docs/evidence/model-compare-20261102/laya-topic-85.json.
- 결과: 규칙과 같은 분류 35/85, 평균 0.32초/질문(규칙은 사실상 0초).
  다른 50개는 대부분 Laya 오분류: "장기재직휴가 며칠이야?"(휴가)를 초과근무로 16건, "경찰공무원 공가"를 징계로, "출장 일비 지급 기준"을 복무 일반으로.
  확신도도 대부분 0.2~0.4로 낮다. 문서 예시("I was charged twice", billing 여부)에도 billing 확률 0.07로 답했다.
- 결론: 지금 상태의 Laya는 공무담 질문 분류에 쓰지 않는다. 쓰려면 공무원 복무 질문으로 학습·조정한 뒤 같은 85문항으로 다시 비교해야 한다.
