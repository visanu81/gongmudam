공무담 v76 · 첫 실행 안내

설치하고 실행하기
1. ZIP을 PC의 폴더에 모두 풉니다. 압축 파일 안에서는 실행하지 마세요.
2. Windows Python 3.12 x64를 설치합니다. Python Launcher와 Tcl/Tk를 포함하세요. 폴더·파일 선택 창에 Tcl/Tk가 필요합니다.
   확인: py -3.12 --version
3. 공무담 폴더에서 `1_설치.bat`을 실행하고 완료될 때까지 기다립니다. 패키지 wheel은 설치 파일에 포함되어 있어 인터넷 연결 없이 설치할 수 있습니다.
4. `2_공무담_실행.bat`을 실행한 뒤 브라우저에서 다음 주소를 엽니다.
   http://localhost:8781/desktop/?variant=B
   8781 포트가 사용 중이면 `run.bat --port 8787`로 실행하고 표시된 주소를 사용하세요. 실행 창을 닫거나 Ctrl+C를 눌러 서버를 종료합니다.

예제 자료로 AI 없는 기능 사용하기
1. 공무담 B안에서 `업무자료 정리`를 열어 프로젝트 이름을 만들고 `이 PC 폴더 추가`로 `service/sample_data/projects-v76/교육 자료` 폴더를 추가합니다.
2. `이 PC 파일 추가`로 폴더 바깥의 `service/sample_data/projects-v76/개별 추가/물품 납품.txt`도 추가합니다. 폴더와 개별 파일 선택은 별도의 Windows 선택 창에서 진행합니다.
3. 자료를 읽은 뒤 아래 질문을 입력해 봅니다.
   - 교육 자료 핵심만 간단히 정리해줘
   - 교육 날짜와 회신 마감, 내가 해야 할 일을 정리해줘
   - 두 자료의 마감과 장소 차이를 비교해줘
   - 교육 자료 요약 보고서 초안을 써주세요
4. 답변의 파일명과 행 근거를 열어 원문과 대조합니다. 초안은 담당자가 검토·수정하고 저장할 수 있습니다.

기대할 수 있는 동작
- 요약과 일정·할 일 정리는 자료에 적힌 문장을 주제별로 발췌합니다. 예제에는 회신 마감이 2026-11-06 18:00과 2026-11-09 17:00으로 다르게 적혀 있습니다. 둘 다 표시하고 적용할 문서를 확인하도록 안내해야 합니다.
- 장소도 최초 안내의 `가상 시청 3층 교육실`과 변경 안내의 `가상 시청 5층 회의실`을 각각 보여야 합니다. 변경 안내가 최종 승인·적용되었다고 임의로 확정하지 않습니다.
- 비교 질문은 두 안내 파일을 선택해 질문합니다. 두 자료를 함께 선택하면 각 파일의 마감과 장소 차이를 나란히 비교하고, 어느 쪽이 적용되는지는 담당자 확인으로 남깁니다.
- 보고서 초안은 원문 근거와 함께 구성합니다. 자료에서 확인할 수 없는 목적, 최종 적용 일정·문서, 승인·발송 여부는 `[작성 필요]` 같은 확인란으로 둡니다.
- `항공권 환불 규정을 요약해줘`처럼 등록한 네 파일에 없는 내용을 물으면 근거 부족으로 안내합니다. 교육 질문에는 별도 물품 자료의 기한이나 금액을 섞지 않습니다.

공무담의 기본 질문 처리는 AI 없이 작동합니다. 설치·기본 사용에는 API 키, Node.js, 인터넷 연결, 로컬 AI가 필요하지 않습니다. 답변은 규칙에 따른 원문 발췌와 정형 초안이며 자유 생성형 AI 답변이 아닙니다. 인용 근거는 최대 24단위·24,000글자입니다. 모든 문장이나 읽은 자료 전체가 답변에 포함되는 것은 아니며, 답변에서 인용 범위와 일부 읽음 상태를 확인하세요. 원본 파일은 읽기 전용으로 처리합니다.

로컬 AI는 선택 기능입니다. `업무 설정 → 로컬 AI`에서 Gemma 3:4b 또는 Llama 3.2:3b 프로필과 호환 모델 서버 주소를 설정합니다. 모델 서버와 가중치는 별도로 설치해야 하며 ZIP에 포함되지 않습니다. 설정하지 않아도 네 가지 기본 시나리오를 사용할 수 있습니다. v76의 실제 기능 확인은 AI 없이 수행했습니다.

자료 한계와 보존 자료
현재 프로젝트와 선택한 파일 범위 안에서 질문합니다. TXT·Markdown·CSV·DOCX·XLSX·HWPX 및 텍스트 레이어가 있는 PDF 본문을 읽습니다. 이미지 스캔 PDF OCR과 구형 HWP 바이너리 형식은 지원하지 않습니다. PDF 최대 1,000쪽, 파일 64MB, 파일당 추출문 800만 글자·10만 단위, 처리 시간 60초 제한이 있으며 한도에 닿으면 일부 읽음으로 표시합니다. 공식 자료 스냅샷은 법령·지침 30건과 매뉴얼 PDF 6개(총 221쪽), 36개 원문입니다. 이는 보존된 이전 스냅샷이며 최신 법령·지침으로 갱신되었다는 뜻이 아닙니다.

백업하기 전 서버를 종료한 뒤 공무담 설치 폴더를 복사하세요. 서버가 실행 중인 동안 개인 데이터베이스를 복사하면 자료가 누락될 수 있습니다. 설치본 검증 기록은 `docs/SUBMISSION-v76-VALIDATION.txt`를 참고하세요.
