# 공무담

공무담은 공무 업무 도우미입니다. 승인된 B안 바탕화면에서 v70의 출장정산·자료 취합·업무자료 정리·업무도구함·변경 알림함을 창으로 열어 사용합니다.

공개 주소: **https://gongmudam.visanu81.workers.dev**

Workers에 배포된 화면은 PC의 별도 업무 서버·로컬 AI에 연결됩니다. 해당 PC와 서버·터널이 켜져 있어야 업무 처리가 됩니다. 방문자들이 같은 합성 업무를 공유하는 공개 시연이므로 실제 개인정보·업무자료는 입력하지 마세요.

## 준비 환경

- Windows
- Python 3.12 x64 (`py -3.12` 실행 가능)

## 전체 서비스

`service/`에는 검증된 v70 FastAPI 앱이 포함되어 있습니다. 패키지에 포함된 30개 공개 법령·지침과 6개 업무 매뉴얼(221쪽), 테스트, wheel 파일, 오프라인 설치 구성은 보존되어 있습니다. MPM 복무제도 안내 10종과 FAQ 26건도 원문 사본·해시와 함께 포함합니다. AI 없이 상황별 안내를 사용할 수 있으며, 모델 응답 형식이나 시간이 맞지 않으면 원문 안내를 유지합니다. 개인 데이터베이스, 사용자 설정, 모델 가중치는 포함하지 않습니다.

1. `install-service.bat`을 실행합니다.
2. `run-service.bat`을 실행합니다.
3. 브라우저에서 <http://127.0.0.1:8781/start.html?v=70>을 엽니다.

8781 포트를 이미 사용 중이면 `run-service.bat --port 8787`로 시작합니다.
AI 모델 연결은 선택 사항이며 별도로 운영하는 Ollama를 사용할 수 있습니다.

## 공무담 B안 바탕화면

`desktop/`은 공무담과 수달 마스코트 무무를 담은 B형 화면입니다. 업무 창은 기존 서비스 API를 사용합니다. 메모·소속은 브라우저에 저장되며 소속은 질문에 함께 전달됩니다. 출장 계산에 적용할 기관·규정팩은 출장 화면에서 확인합니다. 로컬 주소와 공개 주소의 브라우저 저장 공간은 서로 다릅니다.

창의 가장자리나 네 모서리를 마우스로 끌어 크기를 조절할 수 있습니다. 조절 손잡이에 키보드 초점을 두고 방향키를 사용해도 됩니다(Shift는 큰 간격). 최대화 후 복원하거나 최소화했다 열어도 조절한 크기를 유지합니다. 좁은 화면에서는 기존 전체 작업공간 배치를 사용합니다.

`install-service.bat`으로 처음 설치한 뒤 `run-desktop.bat`을 실행하고 <http://127.0.0.1:8892/>를 엽니다. 이 명령은 아래 통합 실행과 같습니다. 이전 디자인 실험의 8891 서버와 구분합니다.

## 통합 실행·공개 연결

현재 운영 PC에서는 바탕화면의 **공무담 실행** 아이콘을 더블클릭하면 됩니다. 꺼진 서버와 Cloudflare 터널을 순서대로 시작하고 연결을 확인한 뒤 같은 공개 주소를 엽니다. 이미 실행 중이면 그대로 사용합니다. 준비 창이나 브라우저를 닫아도 서버와 터널은 계속 실행됩니다.

바로가기를 다시 만들려면 프로젝트의 `install-desktop-shortcut.bat`을 실행합니다. 프로젝트 폴더를 이동한 경우에도 이 설치 파일을 다시 실행하세요. 이 설치 파일은 로그인 자동실행을 등록하지 않습니다. 현재 운영 PC의 별도 설정과 실제 실행 검증은 [바탕화면 실행 안내](docs/DESKTOP-LAUNCHER-20261024.md)를 참고하세요.

현재 PC에는 별도로 **공무담 자동실행** 바로가기를 Windows 시작프로그램에 등록했습니다. 로그인할 때 브라우저 창 없이 로컬 서버(8892)와 기존 터널을 시작하며, 이미 실행 중이면 재사용합니다. 실제 바로가기 실행에서 준비 상태와 재사용 동작을 확인했지만 물리적인 재부팅은 하지 않았습니다. 이 PC별 설정은 로컬 `.local-runtime/launcher/autostart.json`에 기록되며 저장소나 새 설치 ZIP에는 포함되지 않습니다. 해제하려면 `Win+R`에서 `shell:startup`을 열고 **공무담 자동실행** 바로가기만 삭제하세요.

다른 PC에서 처음 구성하거나 터미널로 실행할 때는 다음 순서를 사용합니다.

1. 처음에는 `install-service.bat`을 실행합니다.
2. `run-gongmudam.bat`을 실행하고 <http://127.0.0.1:8892/>를 엽니다.
3. 공개 주소를 연결할 운영 PC에는 Node.js를 설치하고 `npm ci`를 실행합니다. 별도 터미널에서 `run-tunnel.bat`을 실행합니다. 해당 Cloudflare 계정의 로그인 권한이 필요합니다.

통합 실행은 `.local-runtime/service`에 별도 공개 시연 실행본을 만듭니다. 기존 개인 DB·설정은 복사하지 않으며, 다시 실행할 때 공개 시연 업무를 보존합니다. Workers 화면·코드를 갱신할 때는 `npm run deploy`를 사용합니다. 다른 Cloudflare 계정에서는 전용 터널·VPC 서비스를 만들고 `wrangler.jsonc`를 변경해야 합니다. 자격증명은 저장소에 넣지 않습니다.

## v70 통합 확인

승인된 공무담 B안에 v70 기능·자료를 통합했습니다. 새로 실행하려면 위의 `run-gongmudam.bat` 또는 바탕화면 실행 아이콘을 사용하세요. 기존 공개 실행본은 별도의 백업·추가 등록 절차로 갱신했고 업무·첨부·모델 선택을 보존했습니다. 자세한 검증 범위와 두 모델 응답 차이는 [v70 통합 검증 기록](docs/INTEGRATION-v70-20261024.txt)을 참고하세요.

## v71 로컬 AI 근거 선택

로컬 모델의 근거 선택 요청에 후보 ID와 `null`만 허용하는 JSON 스키마를 지정합니다. 모델이 선택한 구절은 실제 원문에 있는지 다시 검사하며, 답변의 법령 문맥과 원문 안내는 유지합니다. [동일 질문 두 모델 검증 기록](docs/LOCAL-AI-v71-20261025.txt)을 참고하세요. 기존 업무와 등록 자료를 보존한 상태로 실행본도 갱신했습니다.

## v72 다른 PC용 제출본

공무담 B안과 v71 AI 개선을 포함하는 새 로컬 설치 ZIP을 제공합니다. ZIP의 `1_설치.bat` 후 `2_공무담_실행.bat`을 실행하면 Cloudflare·Node 없이 내 PC의 B안 화면이 열립니다. 기본 AI는 offline이며 모델은 선택 사항입니다. 설치 전제와 실제 검증 범위는 [처음 실행 안내](docs/SUBMISSION-v72-START.txt), [v72 검증 결과](docs/SUBMISSION-v72-VALIDATION.txt)를 확인하세요. 업무도구함은 28개 카드와 검색·분류로 정리하고 기존 화면이 잠깐 섞이는 현상을 수정했습니다.
