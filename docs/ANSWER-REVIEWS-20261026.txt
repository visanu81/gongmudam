공무담 실무 질문·답변 검토함 — 사용 안내와 검증 결과
확인일: 2026-10-26 / 실제 사용하는 개인용 앱: http://127.0.0.1:8787

사용 방법
1. 공무담 B안의 서무 안내에서 질문합니다. 로컬 AI 보조를 끈 상태에서도 사용할 수 있습니다.
2. 답변 아래에서 해결됨 / 틀림 / 근거 부족을 선택합니다. 의견을 함께 남길 수 있습니다.
3. '검토함에서 열기' 또는 서무 안내 상단 '질문·답변 검토함'을 누릅니다.
4. 기존 답변과 근거를 확인한 뒤 답변, 검토자 이름, 적용 기간, 변경 이유를 입력합니다.
5. '등록 자료에서 근거 선택'에서 검색합니다. 원문을 펼쳐 확인하고 '원문 인용'을 누르거나
   해당 자료를 선택한 뒤 원문에 실제로 있는 인용문을 입력합니다. 수정 답변의 근거는 1~6개입니다.
6. '검토 초안 저장'을 누릅니다. 이 시점에는 기존 답변이 유지됩니다.
7. 원문과 적용 범위 확인란을 체크하고 '확인한 초안 적용'을 누르면 다음 질문부터 반영됩니다.
8. '사용 중지'는 적용을 멈추되 원래 의견, 답변, 근거, 수정 버전과 이력을 보존합니다.
   '적용 중지하고 다시 검토'는 적용을 멈추고 열린 검토 목록으로 되돌립니다.

적용 범위
- 같은 확인된 소속(기관·부서·지역·신분), 자료함 선택, 특정 기관 자료 선택에서 적용합니다.
- 검토한 질문과 검토자가 직접 등록한 대체 질문에 적용합니다. 다른 상황에 임의로 확대하지 않습니다.
- 공백·문장 끝 물음표 등 가벼운 차이는 정규화합니다. 자유로운 바꿔 말하기 전체를 자동 해석하지 않습니다.
- 질문 기준일이 적용 기간에 들어야 하며, 근거의 시행일과 질문의 날짜도 확인합니다.
- 원문 해시가 달라지거나 자료가 사용 제외·삭제·소속 불일치가 되면 검토 답변을 쓰지 않습니다.
  검토함에 재검토 필요를 표시하고 기존 안내 경로로 답합니다. 기존 답변도 근거가 없으면 부족함을 안내합니다.
- AI 학습이나 법령 원문 변경 기능이 아닙니다. 저장된 검토 답변을 조회해 제공하므로 AI 연결이 필요 없습니다.
- 원문 인용 일치는 프로그램이 검사합니다. 답변 해석과 인용의 충분성은 검토자가 확인해야 합니다.
- 개인용 로컬 PC용입니다. 검토자 이름은 감사 기록용 입력값이며 로그인 인증·기관 공식 승인 기능이 아닙니다.
  공개 시연 모드에서는 변경 API와 검토 답변 적용이 차단됩니다.

저장과 보존
- 별도 service/data/answer-reviews.db에 의견·수정 버전·변경 이력·적용 질문을 저장합니다.
- SQLite 트랜잭션과 revision을 확인합니다. 동시 변경은 409, 잘못된 근거나 미확인 적용은 422입니다.
- 처음 수집한 답변·근거는 원본 스냅샷으로 남고 수정안은 별도 버전으로 저장됩니다.
- 저장한 초안은 다시 열어 이어서 수정할 수 있습니다. 아직 저장하지 않은 화면 편집은 페이지 안에서만 유지됩니다.
- 기존 자료, 출장 계산, 프로젝트·업무, 모델 설정 및 제출용 v79 ZIP은 덮어쓰지 않았습니다.
