공무담 제출본 v74 검증 기록 · 2026-10-25

검증 범위
v74는 B안 바탕화면에 로컬 프로젝트 자료 추가·읽기·질문·근거 표시와 초안 편집·저장을 통합했습니다. 기존 출장정산, 자료 취합, 달력, 매뉴얼, 최근 업무 기능도 같은 설치본에서 확인했습니다. 프로젝트 기능은 기존 공식 법령·매뉴얼 등록 자료와 별도이며 원본 파일을 수정하지 않습니다.

새 설치에서 확인한 프로젝트 기능
- 실제 HTTP 경로를 통해 PDF 25쪽의 문구를 찾고, 엑셀 6번째 시트 501행의 내용을 찾았습니다.
- 질문과 무관한 내용을 답하지 않았고, 근거 파일·위치·발췌가 원문과 일치했습니다.
- 초안을 편집해 저장한 뒤에도 변경 내용이 남았고 입력한 원본 파일은 그대로였습니다.
- 새 설치본에서 같은 교육 회신 마감 질문으로 실제 로컬 모델 두 개의 응답을 확인했습니다.
  - Gemma 3:4b: 16.672초
  - Llama 3.2:3b: 16.297초
  두 모델 모두 교육 안내 TXT와 엑셀의 회신 마감 근거를 선택했습니다. 마감과 미회신 부서를 함께 묻는 복합 질문은 기존 공개 앱에서 Gemma 14.610초·Llama 8.125초로 별도 검증했으며 public-two-models.json에 기록했습니다. 시간은 이 검증 환경의 단일 실행 결과이며 성능 보증이나 비교 벤치마크가 아닙니다.
- 실제 API로 폴더 안 문서 3개와 폴더 밖 개별 Markdown 파일을 각각 등록했습니다. PDF 25쪽, 엑셀 6번째 시트 501행의 정확한 위치 검색과 무관한 질문의 근거 없는 답변 방지를 확인했고 원본은 변경되지 않았습니다.
- 새 설치 서비스의 Python 검사 807개, 루트 Python 검사 18개, 루트 Node 검사 31개, 서비스 Node 검사 25개를 통과했습니다. 루트 검사에는 새 시작 주소·허용 경로·홈 복원과 캐시된 HTML의 304 우회 방지 확인이 포함됩니다. 설치본의 Python 검사는 159.665초(실행기 기준 163.082초) 걸렸습니다.
- 프로젝트 본문 추출 검사 23개, 폴더 회귀 검사 136개, 작업 연결 검사 4개, 핵심·시작 동선 묶음 검사 65개를 통과했습니다. 검색 시 본문 전체를 메모리에 쌓지 않고 제한된 후보를 유지하며, 1만 본문 단위 메모리 피크 검사도 8MB 미만으로 통과했습니다.
- 공개 서비스의 상태·최근 업무·출장·자료 취합·달력·자료함 API가 모두 HTTP 200을 반환했습니다.
- v74 공개 실행본의 관리 해시 일치, 공개·개인 모드의 연결 상태, 기존 8781 개인 런타임 보존을 확인했습니다.

기존 자료와 제한
등록 자료는 총 36건(법령·지침 30건, e-사람 매뉴얼 PDF 6개·전체 색인 221쪽)입니다. 별도 인사혁신처 복무 안내 10종과 FAQ 26건도 보존합니다. 새로 설치한 자료의 원본 자산 해시가 기존 등록 자료와 일치함을 확인했습니다. 법령·매뉴얼 자격과 확인 시점은 새 버전이라는 이유로 갱신되지 않습니다. 프로젝트 문서는 공식 근거로 자동 등록되지 않습니다.

PDF는 최대 1000쪽, 본문 추출 파일 64MB, 파일당 추출문 800만 글자·10만 단위, 압축 문서 펼친 크기 20MB·512항목, 파일당 처리 시간 60초 제한입니다. PDF 이미지 OCR과 HWP는 지원하지 않습니다. Word 일부 영역, 복잡한 표·서식은 추출이 불완전할 수 있습니다.

실제 새 설치본의 run.bat --port 8896 --no-browser 실행에서 v74 개인용 B안 바탕화면과 offline 기본 설정을 확인했습니다. /index.html#home을 새로고침하면 B안 바탕화면으로 이동하고, /folders.html#project=<id> 직접 링크도 같은 프로젝트가 열린 B안 창으로 연결됩니다. 새 탭의 바탕화면 링크와 홈 버튼의 최소화·복원 중 미전송 질문 유지도 확인했습니다. 상위 서비스 진입점과 캐시 버전 표식이 갱신되어 구형 북마크와 저장된 페이지에서 새 스크립트를 사용합니다.

새 설치 및 이동 검증
후보 RC1 ZIP을 같은 개발 PC의 한글·공백 경로 `.local-verification/v74_새 설치 검증/공무담`에 풀고 새 가상환경을 만들었습니다. `install.bat`이 포함 wheel만으로 설치하고 pip check를 통과했습니다(42.568초). 새 설치 폴더에서 `run.bat --port 8896 --no-browser`로 실행했습니다. 루트 Python 18개, 루트 Node 31개, 서비스 Node 25개 검사도 통과했습니다.

그 설치 폴더를 `.local-verification/v74_경로 이동 검증/공무담`의 한글 경로로 복사해 재실행했습니다. 패키지가 관리하는 공식 원문 36건의 경로가 새 위치에 맞게 다시 연결됐고, 프로젝트 대화 6회분과 초안 메모를 보존했습니다. 설정 파일 SHA-256은 그대로였으며, 이동 후에도 PDF 25쪽 검색을 확인했습니다. Python 자체 설치와 AI 모델 가중치는 별도 준비 항목입니다.

이 검증은 새 폴더와 새 가상환경에서 실행한 결과이며 별도 물리 PC 시험은 아닙니다. 새 설치 시간과 모델 응답 시간은 이 PC에서의 단일 실측입니다.

최종 실행 코드와 자산은 최종 ZIP의 관리 파일 해시 및 실제 설치본 파일을 대조해 확인합니다. 이전 v73 ZIP은 보존합니다.
