# 오프라인 서무 지식팩 검증 보고서

검증일: 2026-10-25

## 범위와 자료

개인정보 처리, 기록물 관리, 정보공개, 행정기관 업무 인수인계에 관한 공식 근거팩을 추가했다. 공식 법령·규정 5종에서 조문 24개를 수집·검증하고, 19개 질문 규칙에 연결했다. 등록 자료함의 지식 원문은 기존 50개에서 74개로 늘었다. 저장된 자료는 2026-10-25 현재 확인한 판본이며, 이후 개정이나 시행일 변경을 자동으로 보장하지 않는다.

자료는 공식 원문과 발췌문, 메타데이터, 검토 질문·규칙으로 구성한다. 질문 규칙은 근거 조문을 찾는 안내용이며, 모든 질문이나 기관별 세부 상황을 포괄하지 않는다.

## 동작 검증

- AI를 끈 상태에서 실제 서무 질문 34건을 확인했다. 답변 근거가 있는 질문 19건은 검토된 요약과 해당 원문 인용을 표시했고, 근거가 부족하거나 적용 범위를 벗어난 질문 9건은 답을 보류했다. 기존 예산·휴가·여비·업무 질문 6건도 기존 결과를 유지했다.
- 로컬 모델 연결을 실제로 시도해 `ConnectTimeout`이 발생하는 경우를 확인했다. 이때 AI 비사용 답변과 내용·요약 트리가 같았고, 모델 연결 실패에 의존하지 않고 원문 기반 답변을 제공했다. 새 규칙은 모델 호출 없이 동작하며, 모델이 사용 가능한 경우에도 선택된 인용은 원문과 대조한다.
- 개인정보 열람권리, 14세 미만 아동의 동의, 정보공개 수수료, 반복청구 종결, 개인정보 유출 과태료처럼 필요한 세부 근거나 규칙이 없는 질문은 답을 보류한다. 미래 시행 판본, 과거 기준일, 공공기관 자체 인수인계 규정도 현재 팩의 범위를 벗어나면 답하지 않는다.
- 추가 등록 전후 업무 데이터, 앱 설정, 별도 데이터베이스가 보존된 것을 확인했다. 검증 기록상 기존 지식 원문 50건과 프로젝트·파일·메시지 데이터가 유지됐다.

## 등록과 보존

등록 도구는 기본적으로 변경 예정 항목만 보여준다. 실제 추가는 기존 데이터베이스를 지정하고 `--apply`를 전달할 때만 수행하며, 적용 전에 백업을 만든다. 이미 같은 식별자와 해시로 등록된 원문은 다시 추가하거나 비활성 상태를 바꾸지 않는다. 해시가 다르거나 일부만 등록된 팩은 자동 덮어쓰기 없이 중단한다.

서비스 디렉터리에서 사용할 명령:

```powershell
python -m tools.register_office_pack --db data/folders.db
python -m tools.register_office_pack --db data/folders.db --apply
```

이번 등록은 이미 수행되어 별도 등록 명령을 다시 실행하지 않았다. 등록 결과와 백업 위치는 `docs/evidence/office-offline-20261025/registration.json`에 기록했다.

## 그래프와 테스트

Graphify 코드맵은 193개 파일 기준으로 새로 생성됐고, 상태 기록상 갱신 누락 없이 그래프 산출물과 복사본이 일치한다. 이는 코드 관계를 탐색하는 자료이며 법령의 타당성이나 답변의 법적 근거를 검증하지 않는다. 이번 작업에서 Neo4j 실행 환경은 설치하지 않았다.

최종 서비스 전체 테스트 865개가 통과했고, 실행·통합 관련 루트 테스트 33개도 통과했다. 집중 검증 12개는 서비스 전체 집계에 포함된다. 민감정보·주민등록번호 동시 질문, 민감정보 외부 제공, 정보공개 부분공개와 기한의 동시 질문에서도 필요한 근거를 모두 유지하는지 확인했다. 서무 지식 테스트와 서비스 전체 테스트 명령은 다음과 같다.

```powershell
cd service
python -m unittest discover -s tests -p "test_office_knowledge.py" -v
python -m unittest discover -s tests -p "test_*.py"
```

기존 v76 ZIP은 변경하지 않았다. 다음 배포 묶음에는 재무·서무 지식 코드와 공식 원문, 발췌문, 메타데이터, 질문 규칙 및 등록된 전체 74개 원문을 포함해야 한다.
