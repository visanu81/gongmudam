공무담 v75 · 검증 안내

검증 범위
v75에는 네이티브 폴더·파일 선택기(`native_picker.py`), 프로젝트 질의(`project_query.py`), 관련 라우트·JavaScript·테스트가 포함됩니다. 아래 새 설치 결과는 ZIP을 같은 개발 PC의 새 한글·공백 경로에 풀고 새 가상환경을 만든 뒤 확인했습니다. 별도의 물리 PC에서는 검증하지 않았습니다. v74 검증 보고서와 증거는 과거 버전 기록이며 v75 결과로 인용하지 않습니다.

새 ZIP 설치와 시작
- ZIP을 새 한글·공백 경로에 풀고 새 가상환경에 설치했습니다. 실제 `install.bat` 내부의 pip --no-index가 포함된 wheel만 사용해 설치했고 `pip check`도 통과했습니다. 설치 시간은 47.797초였습니다.
- 설치본에서 `run.bat --port 8896 --no-browser`를 실행해 v75 개인용 화면과 오프라인 기본 상태를 확인했습니다.

설치본 기능 검증
- GUI에서 포함된 예제 폴더와 폴더 밖 파일을 각각 선택했습니다. `담당자 확인 메모.txt` 4행의 `회계과: 미회신`에 대해 `미회신 부서는 어디인가요?`라고 물었을 때 해당 원문 답변과 근거를 확인했습니다. 별도 Windows 선택 창의 소유자 표시는 `공무담 자료 선택`이었습니다. 취소는 사전 소스 GUI와 설치본 자동 검사에서 확인했습니다.
- 실제 설치본 API에서 다른 두 표현(`어느 부서가 아직 회신하지 않았나요?`, `회신 안 한 부서를 알려주세요`), 회신 마감 복합 질문과 자료에 없는 질문을 확인했습니다. 읽는 중 질문 대기는 설치본 자동 검사에 포함됩니다. 질문 표현은 각각 기대한 답과 부재 응답을 반환했습니다.
- 설치본 API에서 25쪽 PDF와 엑셀 6번째 시트 C501의 자료를 찾았습니다. 초안을 저장한 뒤에도 내용이 유지됐고, 근거 없는 질문에 답을 지어내지 않았으며 원본 파일은 바뀌지 않았습니다.
- 서버를 종료했다 다시 시작한 후에도 대화 10건, 파일 2건, 설정 해시가 유지됐고 프로젝트 상태가 준비 완료로 표시됐습니다.
- 설치된 서비스 테스트 818개가 통과했습니다(테스트 실행기 300.958초, 래퍼 기준 307.015초). 별도 검사도 루트 Python 19개, 루트 Node 31개, 서비스 Node 25개가 통과했습니다.
- 공식 원문 자산 36건의 해시는 기존과 같았습니다. 자료 구성은 법령·지침 30건, 매뉴얼 PDF 6개·221쪽입니다. 이 자료는 보존된 v74 지식 스냅샷과 동일하며 이번 검증으로 갱신되지 않았습니다.

사전 소스 단계 확인
새 설치 검증 전에 소스에서 프로젝트·선택기·텍스트 검사 43개와 폴더 회귀 67개(총 110개)를 통과했습니다. 이 단계의 110개 결과는 설치본 서비스 테스트 818개와 별도 기록이며, 둘을 합산하지 않습니다.

범위와 해석
PDF는 텍스트 추출이 가능한 문서만 대상입니다. 최대 1000쪽·64MB, 파일당 추출문 800만 글자·10만 단위, 처리 시간 60초 제한이 있습니다. 이미지 OCR과 HWP는 지원하지 않습니다. 프로젝트 질의는 현재 프로젝트와 선택 범위에 한정됩니다. 기존 등록 자료는 36건(법령·지침 30건, 매뉴얼 PDF 6개·총 221쪽)이며 이는 v74 기준으로 기록된 자료 현황입니다.

로컬 AI는 `업무 설정 → 로컬 AI`에서 선택하는 옵션 기능입니다. 모델 가중치는 패키지에 포함되지 않습니다. v74에서 측정된 로컬 AI 응답 시간은 v74에 한정된 과거 결과이며 v75에서 측정하지 않았습니다. 당시 Gemma 3:4b는 16.672초, Llama 3.2:3b는 16.297초였습니다. 자세한 과거 기록은 `docs/SUBMISSION-v74-VALIDATION.txt`와 v74 증거 자료에 있습니다. 이 수치를 v75 성능으로 해석하지 마세요. v75 기능 검증은 기본 오프라인 설정으로 진행했습니다.

증거 파일
설치 요약은 `docs/evidence/v75/fresh-validation.json`, 프로젝트 질문은 `fresh-project.json`과 `question-evidence.jpg`, PDF·엑셀·초안은 `fresh-long-documents.json`, 공식 자료 해시는 `fresh-knowledge.json`, 재시작 보존은 `fresh-restart.json`에 있습니다. 네이티브 선택기 화면은 `native-picker.png`에, 설치 서비스 테스트 출력은 `service-tests.txt`에 있습니다. `current-source.json`은 v75 소스 기준 자료입니다. 보존된 v74 ZIP은 별도의 과거 제출본입니다.
