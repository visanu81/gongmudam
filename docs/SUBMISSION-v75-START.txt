공무담 v75 · 첫 실행 안내

설치하고 실행하기
1. ZIP을 PC의 폴더에 모두 풉니다. 압축 파일 안에서는 실행하지 마세요.
2. Windows Python 3.12 x64를 설치합니다. 설치 옵션에서 Python Launcher와 Tcl/Tk를 포함하세요. 폴더·파일 선택 창에 Tcl/Tk가 필요합니다.
   확인: py -3.12 --version
3. 공무담 폴더에서 `1_설치.bat`을 실행하고 완료될 때까지 기다립니다.
4. `2_공무담_실행.bat`을 실행합니다. 브라우저에서 아래 주소로 접속합니다.
   http://localhost:8781/desktop/?variant=B
   실행 창을 닫거나 Ctrl+C를 눌러 서버를 종료합니다.

설치 파일에 필요한 Python 패키지 wheel이 포함되어 있습니다. 설치와 기본 사용에 Node.js, Cloudflare, API 키 또는 인터넷 연결이 필요하지 않습니다. 기본 AI는 오프라인 상태입니다. AI 없이 원문 검색과 발췌를 사용할 수 있습니다.

프로젝트 자료 추가와 질문
1. 바탕화면에서 `업무자료 정리`를 열고 프로젝트 이름을 만듭니다.
2. 포함된 예제를 따라 해보려면 `교육 안내 폴더`를 프로젝트에 추가하고, 이어서 폴더 바깥의 `담당자 확인 메모.txt`도 추가합니다. 예제 위치는 `service/sample_data/projects-v75/교육 안내 폴더/교육 계획.txt`와 `service/sample_data/projects-v75/담당자 확인 메모.txt`입니다.
3. `이 PC 폴더 추가` 또는 `이 PC 파일 추가`를 누릅니다. 폴더 선택 창 제목은 `공무담 자료 폴더 선택`, 파일 선택 창 제목은 `공무담 자료 파일 선택`입니다. 창 소유자 표시는 `공무담 자료 선택`입니다.
   선택 창은 브라우저 안이 아닌 별도의 Windows 창으로 열립니다. 보이지 않으면 작업 표시줄에서 창을 확인하세요. 선택 창은 최대 120초 대기하고, 처리 중 버튼은 잠시 비활성화됩니다. 취소해도 기존 자료나 원본 파일은 삭제되지 않습니다.
4. 선택한 폴더와 파일은 이 PC에서 처리됩니다. 별도 업로드가 필요하지 않아 개인 자료를 로컬로 유지할 수 있습니다. 원본 파일은 읽기 전용으로 처리하며 수정하지 않습니다.
5. 프로젝트 자료가 읽힌 뒤 질문합니다. 예제 `담당자 확인 메모.txt` 4행에는 `회계과: 미회신`이라고 적혀 있습니다. 다음 질문으로 확인할 수 있습니다.
   - 미회신 부서는 어디인가요?
   - 어느 부서가 아직 회신하지 않았나요?
   - 회신 안 한 부서를 알려주세요
   답변 근거에서 파일과 발췌를 확인하세요. 자료에 답이 없으면 확인할 수 없다고 응답합니다. 임의의 모든 질문에 생성형 AI처럼 답한다고 보장하지 않습니다.

로컬 AI (선택)
로컬 모델을 사용하려면 `업무 설정 → 로컬 AI`에서 프로필과 연결을 설정합니다. 프로필은 Gemma 3:4b와 Llama 3.2:3b입니다. 모델 가중치는 ZIP에 포함되지 않으며, 별도의 호환 로컬 모델 서버와 해당 모델 설치가 필요합니다. 설정하지 않아도 기본 오프라인 검색을 사용할 수 있습니다.

자료 범위와 제한
질문은 현재 프로젝트와 선택한 자료 범위 안에서 처리됩니다. 지원 형식의 텍스트와 텍스트 레이어가 있는 PDF를 읽습니다. PDF는 최대 1000쪽, 본문 추출 파일은 64MB, 추출문은 파일당 800만 글자·10만 단위까지 처리하며 파일당 처리 시간은 60초입니다. 한도에 닿으면 일부 읽음으로 표시합니다. 스캔 이미지 PDF OCR과 HWP는 지원하지 않습니다. 프로젝트 자료를 법령·지침 등 공식 등록 자료로 간주하지 마세요. 기존 등록 자료는 법령·지침 30건, 매뉴얼 PDF 6개(총 221쪽)이며 이 수치는 v74 기준 기록입니다.

포트와 백업
기본 포트 8781이 사용 중이면 공무담 폴더에서 `run.bat --port 8787`로 실행하고 실행 창에 표시된 주소를 사용하세요. 백업하기 전 서버를 종료한 뒤 공무담 설치 폴더를 복사하세요. 개인 데이터베이스를 복사하는 동안 서버가 실행 중이면 자료가 누락될 수 있습니다.

v75 검증 기록은 `docs/SUBMISSION-v75-VALIDATION.txt`를 참고하세요.
