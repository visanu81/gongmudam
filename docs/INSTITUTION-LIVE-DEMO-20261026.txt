공무담 v77 실제 앱 화면 시연 — 2026-10-26

대상: 실제 개인용 앱 http://127.0.0.1:8787/desktop/?variant=B&v=77
방식: 화면에서 작성·저장·비교·적용·질문·근거 펼치기·적용 해제를 수행했다.
API는 결과 읽기와 원문 해시 대조에만 사용했다. 프로그램 코드나 제출 ZIP은 변경하지 않았다.

공무담 화면시연기관의 합성 자료 2건을 새로 등록했다.
1. [화면시연·합성] 시연자료 제출 지침 — 종류: 기관 지침
2. [화면시연·합성] 시연자료 제출서 — 종류: 서식
모두 실제 법령·기관 규정이 아닌 기능 시연용 자료다.

지침 시연
v1의 '교육 시작 3일 전'을 비교 후 적용했다.
로컬 AI 보조 사용 체크를 끈 상태에서 다음 질문을 입력했다.
공무담 화면시연기관 시연자료 제출 기한은?
답변은 '교육 시작 3일 전'이며 근거에는 편집 본문 v1과 해시가 표시됐다.

본문을 '교육 시작 5일 전'으로 고쳐 v2 초안으로만 저장했다.
비교 화면에는 3일 전 → 5일 전이 표시됐지만, 적용 전의 같은 질문에는 여전히
v1의 3일 전을 답했다. v2를 비교·적용한 뒤에만 5일 전으로 답변과 근거 버전이 바뀌었다.
v1 원문 해시: a91c72f5f3b67479df03a1329c1ec2ecc3d90304c5dcda0b7ec2e4806bbe292e
v2 원문 해시: a393b1f98cbbc084febab270afc7bfe04b42b31b30b17f90c5e79725c21f5f6b

서식 시연
v1 필수 항목: 제출부서·작성자·제출일.
질문: 공무담 화면시연기관 시연자료 제출서의 필수 항목은?
AI 없이 세 항목을 원문에서 안내했다.
서식 본문에 연락처를 추가하고 v2를 저장·비교·적용한 뒤 같은 질문을 했다.
답변은 연락처를 포함한 네 항목으로 바뀌었고 원문 근거도 v2로 연결됐다.
원본 레이아웃 파일 편집 시연이 아닌 등록 본문의 개정 시연이다.

정리와 보존
시연 후 두 자료 모두 적용 해제하여 일반 답변에 사용되지 않도록 비활성으로 두었다.
각 자료의 두 버전과 변경 이력, 이전·현재 원문을 보존했다.
기존 프로젝트 5개, 자료 12개, 대화 46개와 모델 설정은 유지됐다.

확인한 보완점
- 기관 자료 관리에서 등록한 서식이 안내의 '관련 서식' 영역에 자동 연결되지 않는다.
- 서식의 근거 종류가 '기관 지침'으로 표시된다. 서식임을 구분해서 표시할 필요가 있다.
- 동일한 관리 링크로 반복 이동할 때 한 차례 화면이 전환되지 않았다.
  자료·업무 설정 → 기관 자료 관리 메뉴로 이동해 시연을 이어갔다.
이 세 가지는 이번 시연에서 발견한 후속 개선점이며 수정 완료로 간주하지 않는다.
