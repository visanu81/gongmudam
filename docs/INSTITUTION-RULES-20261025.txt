공무담 — 기관 규정·서식의 버전 관리와 AI 없는 답변 연결
확인일: 2026-10-25

1. 이번 변경
기존 '등록 문서' 화면(index.html#docs) 안에 '기관 규정·서식 관리'를 추가했다.
별도의 바탕화면 메뉴는 추가하지 않았다. 서무 안내의 '자료·업무 설정'에서
'기관 자료 관리'로 들어가거나 아래 주소로 열 수 있다.
http://127.0.0.1:8787/desktop/?variant=B&open=%2Findex.html%23docs

자료 작성 → 초안 저장 → 버전 비교 → 이 버전을 답변에 적용 순서로 사용한다.
본문·자료명·종류·기관·연결어·시행일·적용 범위 메모를 새 버전으로 저장한다.
저장만 한 초안은 답변에 쓰이지 않는다. 적용 해제·삭제는 답변에서 제외하며,
삭제 자료는 복원할 수 있다. 복원 직후에는 비활성 상태를 유지한다.
모든 저장 버전과 상태 변경 이력을 보존한다. 이전 답변의 원문 링크는 해당
버전을 계속 가리킨다. 원본 파일을 수정하거나 덮어쓰지 않는다.

파일 등록은 PDF·DOCX·XLSX·HWPX·TXT·MD·CSV를 지원한다.
전체 추출이 완료된 본문만 허용하며 미지원/이미지 PDF/부분 추출은 안내한다.
편집 대상은 추출 텍스트이다. PDF/엑셀의 시각적 양식을 편집하는 기능은 아니다.
원본 파일 사본과 편집 본문 버전을 각각 보존한다. 파일을 선택한 저장에서는
그 파일의 추출 본문이 새 초안이 되므로, 본문 편집은 저장 후 새 버전으로 한다.

기존 기관 문서·현재 전체 본문을 읽은 일반 자료는 원본을 보존하고 가져올 수 있다.
이 관리 화면에서 공통 법령팩·공식 매뉴얼을 수정 대상으로 가져오지는 않는다.
기존 문서 관리 기능은 화면 아래 접기 영역에 유지했다.

2. 답변 연결과 적용 범위
AI를 끈 상태에서도 담당자가 명시적으로 적용한 버전을 검색·발췌한다.
기관 이름과 등록한 연결어를 질문에 포함해야 한다. 기관명 누락/불일치는
기관 확인을 요구하며 다른 기관의 본문을 임의로 사용하지 않는다.
'이 자료로 질문하기'는 해당 자료와 공통 근거를 함께 확인하도록 대화로 연결한다.
발췌에는 버전·원문·위치·SHA-256을 연결한다. 기관 자료는 별도 가지로 보여주며
공통 법령을 대체하지 않는다. 일반 출장·휴가·물품 안내 주제도 유지한다.
법적 적합성이나 새 여비 계산 기준을 자동 승인하지 않는다.
미래 시행일은 초안으로 보관한다. 과거 날짜의 규정 적용은 자동 추정하지 않는다.
등록 연결어가 없는 모든 자연어 질문을 답하도록 학습한 기능은 아니다.

3. 저장 및 API
folders.db에 institution_rule_docs / institution_rule_versions /
institution_rule_events를 추가했다. 원본 파일 사본은 같은 data 폴더 아래의
institution-rule-assets에 저장한다. 기존 테이블의 행은 수정하지 않았다.

GET   /api/institution-rules
GET   /api/institution-rules/{id}
POST  /api/institution-rules                         초안 작성
POST  /api/institution-rules/{id}/versions           새 초안 버전
GET   /api/institution-rules/{id}/compare            본문·자료 정보 비교
PATCH /api/institution-rules/{id}                   적용·해제·삭제·복원
GET   /api/institution-rules/{id}/versions/{v}/original
GET   /api/institution-rules/{id}/versions/{v}/file
GET   /api/institution-rules/imports
POST  /api/institution-rules/import
POST  /api/institution-rules/upload

변경 요청은 revision을 검사하며 충돌은 409로 반환한다. 적용은 비교한 버전의
해시도 검사한다. 공개 시연 모드의 변경 요청은 403이다.

4. 검증 결과
- 전체 서비스 Python 검사: 888개 통과. 이후 추가한 회귀 사례를 포함한 집중
  Python 검사: 49개 통과(기관 관리 19개 및 기존 안내·업무 지식 검사).
- 최신 서비스 화면 코드 Node 검사: 32개 통과.
- 초안 미적용, 원문 불변, 적용 버전만 검색, 해시 불일치/충돌, 미래 시행일,
  기관 구분, 공통 자료 보호, 원본 파일 보존, 부분 PDF 거부, 공개 변경 차단,
  재초기화 후 유지, 적용 해제·삭제·복원을 검사했다.
- 실제 개인용 앱 8787에서 합성 기관 자료 v1을 작성·비교·적용한 뒤, 본문의
  제출기한 '3일 전'을 '5일 전'으로 변경하여 v2 초안을 저장했다.
  v2 초안 단계의 AI 없는 답변은 여전히 v1 '3일 전'이었다.
  화면에서 v2 적용 후 AI 미사용 답변이 '5일 전'으로 바뀌었으며 v2 원문,
  버전 관리 링크와 SHA-256을 확인했다. 화면의 적용 해제 후 검색에서 빠졌다.
- 실제 API로 삭제 목록 제외/삭제 자료 조회/이전 두 원문 유지/복원 후 비활성/
  이력 7개와 두 버전 보존을 확인했다. 합성 자료는 마지막에 비활성으로 두었다.
  삭제 확인창의 최종 클릭은 이 PC의 네이티브 UI 입력 제한으로 자동화하지
  못했으므로 삭제·복원의 실제 화면 검증 완료로는 계산하지 않았다.
- 기존 등록 자료 86건, 프로젝트 5개, 파일 12개, 프로젝트 대화 46개 및 그 외
  기존 folders.db 테이블의 모든 기존 행이 동일했다. 모델 설정과 별도 업무 DB
  5개의 SHA-256도 동일했다. 공개 앱/터널/제출 ZIP은 이번 작업에서 변경하지 않았다.
- Graphify 갱신 완료: 197파일 / 3,334노드 / 9,785연결, 모델 토큰 0,
  복사·산출물 일치 및 최신 상태 확인.
- Impeccable 정적 점검을 1회 실행했다. 새 관리 화면의 작은 상태 글씨, 낮은
  대비, 초점 표시와 브라우저 기본 fieldset 외곽을 보완했다. 기존 화면 전반의
  숨겨진 화면 제목 계층 등은 이번 국소 변경 범위에 포함하지 않았다.
