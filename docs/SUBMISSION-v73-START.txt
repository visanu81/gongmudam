공무담 제출본 v73 · 처음 실행하는 분을 위한 안내
B안 바탕화면 + 오늘 할 일·이번 주 마감 + 달력 연결 + 자동 변경 문구

가장 먼저 할 일
1. ZIP 전체를 압축 해제합니다. ZIP 안에서 바로 실행하지 마세요. 최신 절차는 루트의 처음읽기.txt를 따르며, service 아래 기존 버전 문서는 엔진 참고 자료입니다.
2. Windows용 Python 3.12 x64가 설치되어 있어야 합니다.
   확인 명령: py -3.12 --version
   Python 공식 설치 안내: https://www.python.org/downloads/windows/
3. 공무담 폴더의 1_설치.bat을 한 번 실행합니다.
   포함된 wheel 파일로 설치하며 처음에는 잠시 기다려야 합니다.
4. 설치가 끝나면 2_공무담_실행.bat을 실행합니다.
   브라우저에 B안 바탕화면이 열립니다.
   기본 주소: http://127.0.0.1:8781/desktop/?variant=B
5. 실행 창은 켜 둡니다. 종료할 때 실행 창에서 Ctrl+C를 누릅니다.

이 제출본의 기본 실행
내 PC용 로컬 실행입니다. Node.js, Cloudflare 계정·터널, 유료 서버 없이 사용합니다.
실행 화면 상단에 '내 PC 업무 공간'이 표시됩니다. 업무 DB와 첨부는 이 설치 폴더의 service/data와 service/output 등에 저장됩니다.
공개 시연 주소의 공유 DB나 개발자의 개인 업무·메모·모델 설정은 포함하지 않았습니다. 이 제출본을 실행한다고 개발 PC나 공개 시연 서버에 연결되지 않습니다.
Python 런타임과 AI 모델 가중치는 별도입니다. 가상환경과 개인 DB를 압축해서 옮기는 방식 대신 포함된 프로그램·공개 자료로 새로 설치합니다.

시작 화면에서 업무 이어가기
오른쪽 '오늘과 이번 주'에서 오늘이 기한인 미완료 업무와 이번 주 마감을 확인합니다. 한국 시간, 월요일~일요일 기준이며 날짜 범위도 표시합니다. 완료한 일과 기한이 없는 일을 오늘 할 일로 임의 표시하지 않습니다.
첫 실행에는 개인 업무·일정이 없어서 0건이 정상입니다. 법령·매뉴얼은 별도로 이미 등록되어 있습니다.
자료 취합에서 합성 교육 업무를 만들고 회신 마감을 오늘로 정하면 홈에 표시되는 것을 확인할 수 있습니다. 항목을 누르면 해당 취합 단계가 열립니다. 달력에서 직접 등록할 때에는 '일정 종류'를 '마감'으로 선택해야 마감 목록에 포함됩니다. 일반 일정은 달력에 표시됩니다.
'달력' 버튼이나 '업무 달력' 아이콘을 누르면 월간 달력을 엽니다. 더 보기와 개별 일정 링크는 해당 날짜·일/주 보기를 전달합니다. 완료·마감 변경 뒤 목록이 갱신되며, '새로고침'으로 직접 확인할 수도 있습니다.
이번 주에 마감이 없고 이후 마감이 있으면 '다음 마감'을 보여줍니다. '하던 일 이어하기'는 펼쳐서 최근 저장한 업무를 확인합니다. 모바일에서는 이 업무 목록을 아이콘보다 먼저 보여줍니다.
인터넷·서버 연결에 문제가 있으면 조회 실패를 표시합니다. 이전 결과가 남아 있으면 최신 정보가 아님을 안내합니다. 오류를 업무 0건으로 표시하지 않습니다.

상단의 짧은 문구
넓은 화면의 상단 중앙에 공무담에서 작성한 문장이 45초마다 바뀝니다. 유명인의 말로 표시하거나 법적 근거로 사용하는 문구가 아닙니다. AI와 인터넷 없이 동작합니다.
'다음 문구' 버튼으로 바꾸고, 자동 변경 버튼으로 멈추거나 다시 켤 수 있습니다. 좁은 화면에서는 업무 입력과 날짜 공간을 위해 숨깁니다. 자동 변경 정지 선택은 현재 브라우저에 저장되며 다른 PC의 설정과 공유되지 않습니다.

AI 없이 먼저 사용해 보기
첫 실행은 offline 모드입니다. AI 보조를 켜지 않아도 등록 원문을 검색하고 처리 순서·근거·매뉴얼을 확인할 수 있습니다.
바탕화면 아래 검색창에 다음을 입력하고 Enter를 누르세요.
- 국가공무원인데 아이가 아파서 병원에 같이 가야 해. 어떤 휴가를 써야 해?
- 국가공무원 본인 병가를 쓸 때 진단서가 필요한가요?
- 국가공무원 건강검진은 어떤 휴가인가요?
- 국가공무원 겸직 허가는 언제 받아야 하나요?
- e-사람 초과근무 사후신청 목록이 안 보여요.
답변에서 근거 버튼을 눌러 조문·출처를 확인하고, e-사람 사용법을 펼쳐 PDF 쪽수와 원본을 열어보세요.
기관·신분·시행 시점에 따라 적용 여부가 달라집니다. 등록한 근거가 부족하면 확인할 내용을 안내합니다.

포함한 자료
- 등록 법령·지침 30건과 e-사람 매뉴얼 PDF 6개, 전체 색인 221쪽.
- 별도 인사혁신처 복무 안내 10종과 FAQ 26건의 원문·출처·해시.
- 여비 규정·별표·계산 기준과 검증된 원문 사본.
- 기관 검색에 사용하는 공개 기관코드 자료.
자료는 AI 모델의 학습 가중치와 분리되어 있습니다. 모델을 바꾸어도 등록 자료를 그대로 검색합니다.
현재 규정 확인 기간은 포함한 인증서 기준입니다. 새로 설치했다는 이유로 최신 확인 기간을 연장하지 않습니다. 변경 확인이 필요한 기간은 앱 안내를 따르세요.

업무도구함
바탕화면의 업무도구함을 누르면 도구 카드가 열립니다. 검색·분류로 도구를 골라 PDF·사진·문서를 처리합니다.
도구 작업 후 '전체 도구'로 목록에 돌아갈 수 있습니다. 생성 결과는 내려받거나 진행 중인 출장정산·자료 취합 업무에 참고 첨부할 수 있습니다.
첨부한 파일이 실제 지급·승인·취합 행에 자동 반영된 것으로 보지 마세요. 검토는 해당 업무에서 진행합니다.
'별도 사이트' 표시 도구는 인터넷 연결이 필요합니다.

로컬 AI 두 모델 사용하기 (선택 사항)
1. 별도로 Ollama를 설치하고 실행합니다. 공식 주소: https://ollama.com/download/windows
2. 인터넷이 되는 환경에서 필요한 모델을 준비합니다.
   ollama pull gemma3:4b
   ollama pull llama3.2:3b
3. 공무담 시작 메뉴의 로컬 AI 설정을 엽니다.
   직접 주소: http://127.0.0.1:8781/local-ai.html
   모델 설정 화면: http://127.0.0.1:8781/index.html#settings
4. local_gemma 또는 local_llama를 선택하고 실제 연결을 확인합니다.
   기본 서버 주소: http://127.0.0.1:11434/v1
   모델 이름: gemma3:4b / llama3.2:3b
5. 서무 안내 입력칸의 '로컬 AI 보조 사용'을 켜고 질문합니다.
   AI를 사용한 경우 화면의 AI 사용 표시와 근거를 확인하세요.
처음 모델을 불러오거나 PC 부하가 큰 경우 AI 보조의 30초 제한을 넘을 수 있습니다. 이때 등록 원문 안내는 계속 표시됩니다. 모델이 준비된 뒤 다시 질문하고 AI 사용 표시를 확인하세요.
두 모델은 같은 질문과 자료로 검증했습니다. 형식이 맞지 않거나 모델 연결에 문제가 있어도 원문 안내를 유지합니다.
AI는 등록한 근거 후보를 고르는 역할입니다. 금액·기한·규정 문구를 새로 만들어 법적 근거로 사용하지 않습니다.

심사단 또는 다른 모델 서버 연결
모델 설정에서 OpenAI 호환 로컬 서버의 base URL과 실제 모델 이름을 지정할 수 있습니다.
예: http://127.0.0.1:8000/v1 (끝의 /v1 포함). 모델 이름은 서버에 등록된 이름과 같아야 합니다.
서버가 JSON Schema 응답 형식을 지원해야 AI 근거 선택 형식 제약을 사용할 수 있습니다. 미지원·오류 시 검증되지 않은 모델 문장 대신 등록 원문을 표시합니다.
명령으로 설정할 때는 service 폴더에서 실행합니다.
.venv\Scripts\python.exe tools\configure_submission_model.py --profile judge_model --base-url http://127.0.0.1:8000/v1 --model 실제모델이름
프로필을 바꾼 뒤 연결 상태와 서무 안내의 AI 사용 여부를 확인하세요.

열리지 않을 때
- Python이 없거나 3.12 x64가 아니면 설치 파일이 안내하고 중단합니다. Python을 준비한 뒤 1_설치.bat을 다시 실행하세요.
- 8781을 다른 프로그램이 사용하면 실행을 중단하고 주소를 안내합니다. PowerShell에서 다음처럼 다른 포트로 실행할 수 있습니다.
  .\run.bat --port 8787
  주소: http://127.0.0.1:8787/desktop/?variant=B
- AI 연결이 안 되면 Ollama 실행 여부와 모델 이름을 확인하세요. AI 보조를 끄면 등록 자료 안내를 계속 사용할 수 있습니다.
- '서버에 연결할 수 없음'이면 공무담 실행 창이 열려 있는지 확인합니다.
- 폴더를 옮긴 뒤에는 실행 파일을 다시 누르세요. 프로그램 소유의 원문 경로를 재연결하고 기존 업무를 보존합니다. 자료를 개별 삭제했거나 원문이 바뀐 경우에는 자동으로 덮어쓰지 않습니다.
- 브라우저에 저장하는 메모·소속과 PC에 저장하는 업무 DB는 저장 위치가 다릅니다. 브라우저 주소·프로필을 바꾸면 메모·소속을 다시 설정해야 할 수 있습니다.

백업과 제출 확인
업무를 백업할 때는 서버를 종료한 뒤 폴더 전체를 복사하세요. data 폴더만 임의로 옮기거나 원문 해시를 바꾸지 마세요.
이 ZIP은 새 설치용입니다. 개인 사용 후 생긴 service/data, config.json, output, 모델 가중치를 심사용 새 ZIP에 임의로 추가하지 마세요.
현재 개발 PC의 Windows 로그인 자동 실행 설정은 이 새 설치 ZIP에 복사하지 않습니다. 다른 PC에서는 실행 파일로 앱을 시작합니다.
전체 패키지 해시는 별도 SHA256.txt에서 확인합니다. 내부 gongmudam-manifest.json과 service/submission-manifest.json에는 포함 파일의 해시가 있습니다.
실제 설치·화면·두 모델 검증 범위는 docs/SUBMISSION-v73-VALIDATION.txt와 docs/LOCAL-AI-v71-20261025.txt를 참고하세요.
