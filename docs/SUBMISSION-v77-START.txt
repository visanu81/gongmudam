공무담 v77 · 첫 실행 안내

설치하고 실행하기
1. ZIP을 PC의 폴더에 모두 풉니다. 압축 파일 안에서는 실행하지 마세요.
2. Windows Python 3.12 x64를 설치합니다. Python Launcher와 Tcl/Tk를 포함하세요. 폴더·파일 선택 창에 Tcl/Tk가 필요합니다. 확인 명령은 `py -3.12 --version`입니다.
3. 공무담 폴더에서 `1_설치.bat`을 실행합니다. 설치 파일에 포함된 wheel을 사용하므로 인터넷 없이 설치할 수 있습니다.
4. `2_공무담_실행.bat`을 실행하고 브라우저에서 `http://localhost:8781/desktop/?variant=B`를 엽니다. 규정 관리 화면을 바로 열려면 `http://localhost:8781/desktop/?variant=B&open=%2Findex.html%23docs`를 사용하세요. 포트를 바꾸려면 `run.bat --port 8787`을 실행하고 표시된 주소를 엽니다. 서버 종료는 실행 창에서 Ctrl+C입니다.

기관 규정 예제로 기능 확인하기
1. B안의 `서무안내 > 자료·업무설정 > 기관자료관리`로 이동합니다.
2. 기관 `합성 제출검증기관`과 키워드 `검증자료 제출`을 사용해 제목 `[합성 예제] 교육자료 제출 안내`인 문서를 만듭니다. `service/sample_data/institution-rules-v77/제출기한_v1.txt`를 원문으로 등록해 초안으로 저장합니다.
3. 저장된 초안을 비교한 다음 v1을 적용합니다. AI 설정은 끈 상태로 진행합니다.
4. 질문에 `합성 제출검증기관 검증자료 제출 기한은?`을 입력합니다. 현재 적용한 v1의 “교육 시작 3일 전”이 원문 근거와 함께 답변에 쓰이는지 확인합니다.
5. 같은 문서에 `제출기한_v2.txt`를 새 초안으로 등록하고 저장합니다. 아직 적용하지 않은 상태에서 같은 질문을 하면 답변은 계속 v1의 3일 전이어야 합니다. 초안을 비교하고 v2를 적용한 뒤 질문하면 5일 전으로 바뀝니다.
6. 원문 보기와 변경 이력을 확인하고, 비활성화·삭제 동작을 살펴봅니다. 삭제한 자료를 복원하면 비활성 상태로 복원됩니다. 필요하면 다시 활성화하고 적용 상태를 확인하세요.

이 두 TXT는 기능 확인을 위해 만든 합성 예제이며 실제 기관의 규정·정책·제출기한이 아닙니다. 예제 자료는 새 PC에 미리 적용되어 있지 않으며, 시험을 위해 사용자가 직접 등록·적용해야 합니다. 적용되는 기관 개정 자료는 해당 PC에 생성·저장되며 학습 모델에 반영되거나 다른 PC로 자동 전달되지 않습니다. 원문 파일은 변경되지 않습니다. PDF·DOCX·XLSX·HWPX·TXT·MD·CSV는 본문 텍스트를 읽는 용도이며 바이너리 파일의 편집이나 원본 레이아웃 편집 기능은 제공하지 않습니다.

로컬 AI는 선택 기능입니다. Gemma 3:4b 또는 Llama 3.2:3b와 호환되는 모델 서버를 설정할 수 있지만 모델 가중치는 포함되지 않습니다. 이번 릴리스에서 실제 모델 재시험을 수행한 것으로 간주하지 마세요. AI를 끄고도 위 기관자료관리 흐름을 확인할 수 있습니다. 기존 `service/sample_data/projects-v76/` 교육 프로젝트 예제도 선택적으로 보존되어 있습니다.

공개 근거 86건(법령·지침 발췌 80건, e-사람 매뉴얼 PDF 6개·221쪽)을 복원합니다. 별도의 복무제도 안내·FAQ 스냅샷과 정형 답변 자료도 포함됩니다. 보관 원문과 해시는 검증하지만 이번 패키지 작업으로 법령의 현행성이나 여비 계산의 적용 기간을 갱신한 것은 아닙니다. 공통 법령팩은 보호하며 기관 자료는 별도 버전으로 관리합니다. 기관명과 키워드를 질문에 함께 넣어야 해당 기관 자료를 찾습니다.

백업하려면 먼저 서버를 종료하고 설치 폴더 전체를 복사하세요. 기관 규정의 DB와 파일 사본은 `service/data` 및 그 하위 `institution-rule-assets`에 보관됩니다. 다른 PC에 새로 설치하면 기존 PC의 개인 업무·대화·기관 개정 자료가 자동으로 따라오지 않습니다. 기존 설치 폴더에 덮어쓰지 말고 새 폴더에 설치하세요. 검증 기록은 `docs/SUBMISSION-v77-VALIDATION.txt`를 참고하세요.
