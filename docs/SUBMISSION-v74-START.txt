공무담 제출본 v74 · 프로젝트 자료와 대화

처음 실행하기
1. ZIP 전체를 압축 해제합니다. ZIP 안에서 바로 실행하지 마세요.
2. Windows용 Python 3.12 x64를 준비합니다. Windows 설치 프로그램에서는 Python Launcher와 Tcl/Tk도 선택해 설치하세요. 폴더 선택 창을 사용하는 기능에 필요합니다.
   확인 명령: py -3.12 --version
3. 공무담 폴더에서 1_설치.bat을 한 번 실행합니다.
   포함된 wheel 파일로 설치합니다. 설치가 끝날 때까지 기다립니다.
4. 2_공무담_실행.bat을 실행합니다. 브라우저에서 B안 바탕화면이 열립니다.
   실행 창은 켜 두고, 종료할 때 Ctrl+C를 누릅니다.

이 제출본은 내 PC에서 실행하는 로컬 업무 공간입니다. Python 3.12 x64가 필요하며 Node.js, Cloudflare 계정·터널, API 키는 필요하지 않습니다. 기본 AI 설정은 offline이며 로컬 AI 모델은 선택 사항입니다. 새 설치본에는 개인 DB, 비공개 업로드, 모델 가중치가 포함되지 않습니다.

프로젝트 자료 시작하기
바탕화면에서 업무자료 정리를 열고 프로젝트 이름을 입력한 뒤 폴더나 파일을 추가합니다. 로컬 앱에서는 선택한 파일을 PC에서 직접 읽습니다. 읽는 동안 질문을 입력해도 저장되어 대기하며, 전체 자료 질문은 읽기 완료 후, 특정 파일 질문은 해당 파일을 읽은 후 처리됩니다. 기본 검색 범위는 프로젝트 전체입니다. 체크박스로 질문할 파일을 좁힐 수 있습니다.

공개 시연 주소는 다른 방문자와 자료를 공유하는 시연 환경입니다. 실제 개인정보나 업무자료를 추가하지 마세요. 공개 화면에서는 시연 자료 추가 또는 자료 관리의 명시적 동의 업로드를 이용합니다.

AI 없이 원문 검색·발췌와 정형 초안을 사용할 수 있습니다. 로컬 AI가 연결되면 원문에서 질문에 필요한 근거를 고릅니다. 답변 근거를 펼쳐 파일명·쪽수·시트/셀·문단과 발췌를 확인하세요. 모델 오류 시 원문 검색으로 전환했다는 안내가 표시됩니다. AI가 만든 내용과 초안은 담당자가 확인하고 수정해야 합니다. 초안은 편집 후 저장·복사·TXT 내려받기를 할 수 있으며 원본 파일은 바뀌지 않습니다.

연결한 폴더는 약 15초마다 확인해 변경 파일만 다시 읽습니다. 원문이 바뀌면 이전 답변의 근거에 변경 표시가 남습니다. 실패하거나 취소한 읽기는 자료 다시 읽기로 재개할 수 있습니다. 프로젝트 문서는 공식 법령·지침으로 자동 등록되지 않습니다. 공식 근거 등록과 분류 등 기존 기능은 자료 관리에서 이용합니다.

파일 처리 범위
PDF는 최대 1000쪽, 본문 추출 파일은 64MB까지 처리합니다. 추출문은 파일당 800만 글자·10만 단위, 압축 문서는 펼친 크기 20MB·512항목, 파일당 처리 시간은 60초 한도입니다. 한도에 닿으면 일부 읽음으로 표시합니다. PDF 이미지 OCR과 HWP는 지원하지 않습니다. Word의 각주·텍스트 상자 등 지원되지 않는 영역이나 복잡한 표·서식은 원문에서 직접 확인하세요.

법령·매뉴얼 등록자료와 프로젝트 파일은 구분되어 있습니다. 등록된 공식 자료의 원문 링크를 그대로 확인할 수 있습니다. 프로젝트 자료의 출처는 답변의 파일·위치·발췌로 확인하고, 그 자료를 공식 근거로 간주하지 마세요.

로컬 AI 사용하기 (선택)
Ollama 등 로컬 OpenAI 호환 서버를 별도로 준비하면 기본 프로필 Gemma 3:4b 또는 Llama 3.2:3b를 사용할 수 있습니다. 실제 설치된 모델에 맞춰 공무담의 로컬 AI 설정에서 프로필과 연결 상태를 확인하세요. 기본 서버 주소는 http://127.0.0.1:11434/v1 입니다. 모델이 연결되지 않아도 offline 원문 검색은 계속 사용할 수 있습니다. 프로젝트 파일 내용을 외부 모델 서비스로 보내는 설정은 이 안내의 로컬 처리 범위에 포함되지 않습니다.

기존 업무도구 찾기
바탕화면의 업무 도구는 내 PC의 공무담 서비스로 연결됩니다. 기존 출장정산·자료 취합·달력·매뉴얼 기능을 사용할 수 있습니다. 올바른 시작 주소는 http://127.0.0.1:8781/desktop/?variant=B 입니다(포트를 바꾸면 해당 포트 사용). 기존 북마크가 /index.html#home 같은 서비스 주소를 열면 B안 바탕화면으로 안내됩니다. 이미 열려 있던 화면이 갱신 후 예전 모습이면 한 번 새로고침하세요. 특정 업무 링크는 바탕화면 안에서 창으로 열리며 기존 작업 화면의 기능을 유지합니다.

실행 문제 해결
- Python이 없거나 3.12 x64가 아니면 설치할 수 없습니다. Python Launcher도 포함해 설치한 뒤 1_설치.bat을 다시 실행하세요.
- 기본 포트가 사용 중이면 다른 포트로 실행합니다: .\run.bat --port 8787. 열리는 주소는 실행 창에서 확인하세요.
- 브라우저 주소로 서비스에 바로 들어간 경우 B안 바탕화면 홈에서 업무를 시작하세요. 특정 업무는 바탕화면의 업무 도구에서 엽니다.
- 프로젝트 파일이 읽히지 않으면 형식·크기·시간 한도와 읽기 상태를 확인한 뒤 자료 다시 읽기를 선택하세요.
- AI 연결에 실패하면 로컬 서버와 모델 이름을 확인하거나 AI 없이 질문하세요.

업무 DB와 프로젝트 자료는 이 설치 폴더의 로컬 서비스 저장 공간에 기록됩니다. 백업 전 서버를 종료하고 공무담 폴더 전체를 복사하세요. 다른 PC로 옮기면 연결한 원본 폴더를 새 PC에서 다시 선택해야 할 수 있습니다. 공개 시연 자료는 여러 사용자가 공유하므로 실제 업무 자료를 사용하지 마세요.
