업무자료 정리 간소화 · 2026-10-26

기본 흐름: 내 프로젝트 → 새 프로젝트(이름만 입력) → 폴더/파일 추가 → 질문.
프로젝트는 자료 목록과 대화를 함께 표시한다. 좁은 화면에서는 자료 목록을 접고 추가 버튼은 유지한다.
기존 자료함 연결, 업로드, 경로/읽기 상태, 작업 취소, 다시 읽기는 자료 관리에서 펼친다.
답변 방식과 세부 읽기 범위는 접어 보이고, 일부 읽음/미확인 자료가 있으면 요약에도 표시한다.
공무담 B안의 상위 환경 안내는 유지하며 프로젝트 내부의 반복 환경 안내를 생략한다.

실제 확인:
- 로컬 B안에서 합성 프로젝트 생성, 네이티브 탐색기 폴더 선택, TXT/MD 3개 읽기 완료.
- 미회신 부서는 어디인가요? → 회계과, 회신 현황.txt 3행.
- 로컬은 offline, 공유는 기존 선택 모델 local_ai. 답변 본문/근거 문장/파일명/위치/원문 해시 동일.
- 양쪽 원문 및 근거 단위 HTTP 200, 원문 파일 해시가 인용 해시와 일치.
- 프로젝트 재진입 시 저장된 자료와 대화 복원 확인. 기존 사용자 자료는 변경하지 않음.
- 공유에 개인 프로젝트/DB/폴더를 복사하지 않고 내장 합성 시연 자료만 사용.
- 프로젝트/본문 색인 28, 요약/비교/초안/선택창 20, 업무 이어가기 4: 총52개 기존 테스트 통과.
- handoff 검사는 개별모듈 실행 때 import경로 오류가 있어 unittest discover 방식으로 다시 실행 후4개 통과.
- JavaScript 문법 검사 통과.
- Impeccable detect의 작은11px 글자 경고는12px 이상으로 수정.
- Graphify 코드 지도 갱신.
