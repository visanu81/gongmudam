공무담 제출본 v72 검증 결과 · 2026-10-25

반영 내용
공무담 B안 바탕화면과 v70 최신 복무 안내·FAQ·매뉴얼 검색, v71 로컬 AI 근거 선택 개선을 함께 묶었습니다.
업무도구함은 기존 사이드 메뉴를 제거하고 검색·분류와 28개 도구 카드로 정리했습니다. 화면 준비가 확인되기 전에는 서비스 프레임을 숨겨 예전 화면이 잠깐 섞이는 현상을 막습니다. 연결 시간 초과·늦은 페이지 로드에도 다시 시도할 수 있습니다.
새 제출본은 Cloudflare 없이 PC 안에서 사용하는 private 실행이며 기본 AI 모드는 offline입니다. 공개 시연과 로컬 설치의 환경 표시를 실제 서버 상태로 구분합니다.

검증 환경과 한계
Windows, CPython 3.12 x64. 개발 PC의 별도 한글 경로에 후보 ZIP을 실제 압축 해제하고 새 .venv를 설치했습니다.
별도 물리 PC에서 시험한 결과는 아닙니다. 개발 환경의 가상환경·개인 DB·API 키·모델 가중치를 복사하지 않은 새 설치와 폴더 이동 시험입니다.
AI 모델 가중치와 Python 자체는 ZIP에 포함하지 않습니다. 모델 시험은 이 PC의 실제 Ollama를 사용했습니다.

처음 설치·실행
- 실제 install.bat 실행 성공: 새 가상환경 생성, 포함 wheel로 --no-index 설치, pip check 통과(약 46.55초, 이 PC 기준).
- 실제 run.bat --port 8894 --no-browser 실행: B안, v72, public_demo=false 확인.
- 기본 8781 사용 중에는 기존 다른 서버로 잘못 연결하지 않고 실행을 거절하는 것 확인.
- 한글·공백이 있는 다른 폴더로 이동 후 실제 run.bat 재실행 성공. 36개 등록 원문 경로 재연결.
- 이동 전후 모델 설정과 업무 DB 5개 내용 동일. 폴더 DB는 원문 경로만 재연결. 합성 출장·교육 업무의 참고 첨부 2건과 원본 해시 유지.
