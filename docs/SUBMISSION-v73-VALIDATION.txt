포함한 개선
공무담 B안에 오늘 할 일·이번 주 마감·다음 마감, 해당 업무 단계와 날짜가 지정된 달력 연결을 포함했습니다. 하던 일 이어하기는 펼침 영역으로 보존했습니다. 모바일은 업무 목록을 아이콘보다 먼저 표시합니다.
상단 중앙에는 공무담에서 작성한 짧은 문장 8개가 45초마다 바뀝니다. 다음 문구와 자동 변경 정지/시작 버튼이 있으며, 정지 선택은 현재 브라우저에 저장합니다. 숨겨진 탭에서는 변경을 쉬고 돌아오면 새 45초 간격으로 시작합니다. 유명인의 말이나 법적 근거로 표시하지 않으며 AI·인터넷 요청 없이 동작합니다. 1280px 미만 화면에서는 다른 조작 공간을 위해 숨깁니다.

설치 환경과 범위
Windows · Python 3.12 x64. 후보 ZIP을 개발 PC 안의 새로운 한글·공백 경로에 실제 압축 해제하고 별도 가상환경을 만들었습니다. 별도 물리 PC에서 시험한 결과는 아닙니다.
실제 install.bat 성공: 새 .venv, 포함 wheel로 --no-index 설치, pip check 통과, 43.07초(이 PC 기준). 실제 run.bat --port 8896 --no-browser 실행에서 v73·private 모드를 확인했습니다. 8781 포트가 사용 중일 때에는 다른 서버로 연결하지 않고 실행을 중단했습니다.
첫 실행은 offline, 업무·일정 0건이었으며 원문 자료는 복원돼 있었습니다. 한글·공백이 있는 다른 폴더로 옮겨 실제 실행 파일로 재시작하고, 등록 원문36건의 경로 재연결과 업무 DB5개·모델 설정·합성 업무2건의 보존을 확인했습니다. Python 자체와 AI 모델 가중치는 별도로 준비합니다. Cloudflare·Node·개발 PC의 자동 실행 설정·API 키·개인 DB는 설치에 필요하지 않습니다.

업무 연결 실측
새 설치 서버에만 합성 교육 업무를 생성했습니다. 오늘 1건·이번 주 2건을 표시하고 홈에서 회신 취합 단계 ID가 포함된 업무 화면으로 이동했습니다. 해당 단계에서 희망자 없음 회신을 확보하고 실제 완료한 뒤 오늘 0건·이번 주 1건으로 갱신됐습니다. 완료 기록과 이전 자료는 남았습니다.
같은 업무 창을 재사용해도 홈 항목을 누르면 해당 단계로 다시 이동합니다. 갱신 응답이 이전 요청보다 늦게 오는 경우와 조회 실패·0건을 구분하는 회귀 검사를 통과했습니다. 동일 결과의 주기 조회에서는 버튼을 보존해 첫 클릭이 사라지지 않습니다.
달력은 2026-12-28~2027-01-03처럼 연도·월 경계를 넘는 주간 이동을 확인했고 날짜·보기 값의 유효성을 검사합니다. 선행 홈 연결 검증과 v73 새 설치 화면을 함께 보관했습니다.
390px/768px 실제 브라우저 폭에서 업무 목록·아이콘·날짜 조작의 배치를 확인했습니다. 넓은 화면에서 문구의 직접 변경·정지·자동 재개와 시간 경과에 따른 변경을 확인했습니다. 화면은 docs/evidence/v73/의 PNG를 참고하세요.

AI 없는 안내·등록 자료
모델 제공자와 외부 네트워크 연결을 금지하고 상황별 질문 12개·FAQ 26개를 점검했습니다. 모두 등록 원문과 일치하는 근거를 찾았고 미등록 질문에 근거·기한을 만들지 않았습니다.

v72에서 같은 소스의 출장·자녀 돌봄·본인 병가 8회 성공 기록도 이전 검증으로 포함합니다. 이번 UI 작업으로 LLM 엔진이나 법령 판단 로직을 변경하지 않았습니다.

자동 검사
새 설치본 최종 서비스 Python 전체 784개 통과(376.737초). 초기 테스트 대기 문제를 보완한 뒤 전체를 다시 실행한 결과입니다.
서비스 JavaScript 25개 통과. 홈 모듈 9개·문구 모듈 5개를 포함하는 바탕화면 Node 검사 30개 통과.
통합 저장소 Python 31개 통과: 제출 버전별 안내 선택, 개인정보 제외, 버전 정보만 변경된 갱신을 포함합니다. 실제 제출 설치 폴더의 통합 Python 17개와 Node 24개도 통과했습니다. 일부 검사는 제출본 내부 검사와 중복입니다.
첫 전체 검사에서 폴더 분석 2건이 테스트의 10초 제한을 넘었습니다. 별도 검사에서도 1000개 파일이 30초 후 708개까지 정상 진행 중이어서, 제품의 문서 해석 허용 45초보다 짧은 테스트 대기 조건을 수정했습니다. 실제 진행이 있을 때만 대기 시간을 갱신하고 120초 전체 상한을 두며, 멈춘 작업·단순 시각 갱신·지속 진행의 상한을 검사하는 3개 가짜 시계 검사를 추가했습니다. 원본 파일 해시·수정 시각·파일 수 검사는 유지했습니다. 제품의 분석 제한·여비 계산·법령 적용은 수정하지 않았습니다.
버전 정보만 바뀌는 업데이트가 이미 완료됐다고 잘못 판단하던 실행기 문제도 수정했습니다. DB·첨부·모델 설정을 보존한 갱신과 재실행의 멱등성을 검사했습니다.

제출물 및 자료 보존
기존 v72 ZIP은 유지하고 별도 v73 ZIP으로 제공합니다. 최초 사용자는 루트의 처음읽기.txt, 1_설치.bat, 2_공무담_실행.bat 순서로 사용합니다. service 아래 기존 버전 문서는 엔진 참고 자료이며 최신 제출 실행 절차는 루트 안내입니다.
전체 ZIP의 SHA-256·압축 CRC·파일 해시는 ZIP 옆 묶음정보.json/SHA256.txt, 내부 gongmudam-manifest.json과 service/submission-manifest.json으로 확인합니다. 최종 ZIP 파일과 실제 설치본 관리 파일의 일치도 검사합니다.
현재 공개 앱은 기존 DB 6개·모델 설정·원문 36건을 보존한 v73입니다. 개인 8781 서버는 변경하지 않았습니다. 개발 PC의 Windows 자동 실행은 별도 PC 설정이며 이 ZIP에 복제하지 않습니다.
