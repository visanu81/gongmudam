공무담 v79 · 첫 실행 안내

설치하고 실행하기
1. ZIP 전체를 Windows PC의 새 폴더에 풉니다. 압축 파일 안에서 실행하지 마세요.
2. Windows Python 3.12 x64를 설치합니다. Python Launcher와 Tcl/Tk를 포함하세요. 파일·폴더 선택 창에 Tcl/Tk가 필요합니다. 확인 명령은 `py -3.12 --version`입니다.
3. 압축을 푼 공무담 폴더에서 `1_설치.bat`을 실행합니다. 포함된 오프라인 wheel로 설치합니다. 앱 실행에는 Node.js, Git, Graphify 설치가 필요하지 않습니다.
4. `2_공무담_실행.bat`을 실행하면 B안 데스크톱 화면이 브라우저에서 열립니다. 기본 주소는 `http://localhost:8781/desktop/?variant=B`입니다. 다른 포트는 `run.bat --port 8787`처럼 지정할 수 있습니다. 서버가 실행되는 콘솔 창은 열어 두세요. 종료하려면 실행 창에서 Ctrl+C를 누릅니다.

처음 확인하기: 공개 공통 자료와 AI 끄기
처음 설치한 AI 설정은 offline입니다. 화면의 `로컬 AI 보조 사용` 체크를 해제한 상태로 공개 공통 자료에 질문해 보세요. 검증된 질문은 `공문을 접수한 뒤 담당 부서로 배부하는 절차는?`와 `공문 기안에서 검토와 결재는 어떤 순서로 하나요?`입니다. 첫 질문은 접수와 문서과의 배부, 담당자 인계 흐름을, 둘째 질문은 전자 기안·검토·협조·결재·등록·시행 흐름을 안내합니다. 답변의 `근거 N`을 누르면 원문 법령 조문/출처, 시행일, 수집일, SHA-256 확인 정보를 보고 원문과 대조할 수 있습니다. 보관한 조문 본문은 인터넷 없이 확인할 수 있고, 외부 공식 출처 사이트를 여는 데는 인터넷이 필요합니다. 이 질문들은 기관 자료 등록이나 합성 예제 설치가 필요하지 않습니다.

이번 묶음에는 행정업무의 운영 및 혁신에 관한 규정 제2·3·6·8·9·10·11·12·18조의 전체 조문과 같은 규정 시행규칙 제15조가 포함됩니다. 규정 조문은 2026-10-02 시행, 대통령령 제36728호이며, 시행규칙은 2023-06-28 시행, 행정안전부령 제408호입니다. 기존 인사혁신처 복무제도 안내·FAQ 보조 파일도 함께 둡니다. 공개 공통 자료는 총 96건으로, 법령·지침 발췌 90건과 e-사람 매뉴얼 PDF 6개(총 221쪽)입니다. 96건이 서로 다른 법령 96개라는 뜻은 아닙니다. 자료는 수집 시점의 보관본이므로 최신성은 원문 출처에서 확인하세요.

AI를 끄고 합성 기관 자료 예제 확인하기
이 예제는 기존 v78과 같은 합성 설정이며, v78 예제 경로를 그대로 사용합니다.

1. B안 화면 아래쪽의 `소속 설정`을 열고 기관을 `합성 제출검증기관`, 신분을 `국가공무원`, 지역을 `서울특별시`로 설정합니다.
2. `서무 안내 > 자료·업무 설정 > 기관 자료 관리`로 이동해 기관 지침을 등록합니다.
   - 제목: `[합성 예제] 연수 참가 접수 안내`
   - 분류: `교육·행사`, 키워드: `연수 신청 접수`, 시행일: `2026-01-01`
   - 원문 파일: `service/sample_data/institution-rules-v78/연수_참가_접수_v1.txt`
   저장한 초안을 비교하고 적용합니다.
3. 같은 기관에 서식을 등록합니다.
   - 제목: `[합성 예제] 교육참가 신청서`
   - 종류: `서식`, 분류: `교육·행사`, 키워드: `교육참가 신청서`
   - 원문 파일: `service/sample_data/institution-rules-v78/교육참가_신청서.txt`
   저장한 초안을 비교하고 적용합니다.
4. AI 사용을 끄고 `교육에 참여하려는데 언제까지 내야 해요?`라고 질문합니다. 적용된 안내의 교육 시작 3일 전 마감과 신청서 원문을 연결해 보여야 합니다. 이어서 `그럼 어떤 양식을 쓰면 돼요?`, `그럼 어떤 항목을 적어야 하나요?`라고 물으면 신청서 이름과 필수 항목(부서, 성명, 연락처)을 원문 근거와 함께 확인합니다.
5. 같은 지침에 `연수_참가_접수_v2.txt`를 새 버전 초안으로 등록합니다. 저장만 한 상태에서는 v1의 3일 전 마감이 유지되어야 합니다. 비교 후 적용하면 v2의 5일 전으로 바뀝니다. 관리 화면에서 `교육·행사` 분류 필터와 버전 이력도 확인합니다. 변경 전 분류와 원문 버전은 이력에 보존됩니다.
6. 이 합성 예제는 다른 기관의 실제 규정이 아닙니다. 모르는 기관의 결재선, 다른 기관에만 해당하는 절차, 요청한 시기의 자료가 확인되지 않는 질문은 임의로 단정하지 않고 확인이 필요하다고 안내해야 합니다.

별도 검증 실행
패키지를 새로 설치한 별도 시험 폴더에서, 공개 공문 접수 질문의 근거 연결을 읽기 전용으로 확인합니다. 이 검증은 등록된 공개 자료 96개의 정확한 구성을 확인하므로, 본인 기관 자료나 합성 예제 문서를 등록하기 전에 실행하세요. 검증 자체는 합성 기관 자료를 만들거나 변경하지 않습니다. 평소 사용하는 설치 폴더에서는 실행하지 마세요.

```bat
service\.venv\Scripts\python.exe service\tools\verify_office_document_submission.py --base http://127.0.0.1:8781 --output office-verification.json
```

이전 기관 문맥 검증기는 합성 자료를 생성하므로 새 설치를 대상으로 별도로 실행해야 합니다. 그 결과와 이번 제출의 최종 검증 기록은 `docs/SUBMISSION-v79-VALIDATION.txt`를 참고하세요.

AI가 꺼져 있어도 고정된 규칙과 검색으로 공개 공통 자료 및 등록한 기관 자료를 근거로 답할 수 있습니다. GraphRAG/Graphify나 학습은 답변에 필요하지 않습니다. 로컬 AI는 선택 기능이고 모델은 패키지에 포함되지 않습니다. 사용하려면 따로 준비해야 하며, 이번 릴리스에서 두 모델의 실제 재시험을 수행한 것은 아닙니다.

합성 예제 자료는 가상 원문이며 실제 기관 규정, 정책 또는 법률 자문이 아닙니다. 예제 파일은 설치 시 자동 등록·적용되지 않습니다. 기관 자료 버전은 로컬 데이터에 보관되며 모델 학습이나 PC 간 자동 동기화를 하지 않습니다. 원문은 변경 없이 보관합니다. PDF·DOCX·XLSX·HWPX·TXT·MD·CSV는 본문 텍스트를 읽는 용도이며 바이너리 원본의 레이아웃을 편집하지 않습니다.

백업할 때는 서버를 먼저 종료하고 공무담 설치 폴더 전체를 복사하세요. 새 PC에 설치해도 기존 PC의 업무·대화·기관 자료가 자동으로 동기화되지 않습니다. 기존 설치 폴더를 덮어쓰지 말고 새 폴더에 설치하세요.
