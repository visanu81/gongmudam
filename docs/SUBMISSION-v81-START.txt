공무담 v81 · 처음 실행하는 분께

1. 설치와 실행
ZIP 전체를 새 폴더에 푸세요. 이전 설치 폴더를 덮어쓰거나 ZIP 안에서 실행하지 마세요.
Windows용 Python 3.12 x64와 Python Launcher, Tcl/Tk를 설치해 주세요.
확인: py -3.12 --version (폴더·파일 선택창에는 Tcl/Tk가 필요합니다.)
1_설치.bat을 실행한 뒤 2_공무담_실행.bat을 실행합니다.
동봉한 wheel을 사용하므로 Python 설치 이후 앱 의존성 설치에는 인터넷이 필요하지 않습니다.
B안 시작 화면: http://localhost:8781/desktop/?variant=B
포트가 사용 중이면 run.bat --port 8789로 실행하세요. 실행 창을 열어 두고, 종료는 Ctrl+C입니다.
Node.js, Git, Graphify, AI 모델은 기본 실행에 필요하지 않습니다.

2. 업무자료 정리: 프로젝트 → 자료 추가 → 질문
업무자료 정리에서 새 프로젝트를 누르고 이름만 입력합니다.
프로젝트 안에서 왼쪽은 자료, 오른쪽은 대화입니다. 작은 화면에서는 자료 목록을 펼쳐 확인합니다.
폴더 추가 또는 파일 추가를 누르면 이 앱이 실행 중인 PC의 선택창이 열립니다.
여러 폴더와 개별 파일을 함께 추가할 수 있습니다. 원본은 변경하지 않고 로컬에서 읽습니다.
선택창이 뒤에 있다면 작업표시줄을 확인하세요. Tcl/Tk가 없으면 Python 설치 구성에서 추가하세요.
읽는 수와 진행 상황을 확인한 뒤 질문합니다. 읽는 동안에도 질문을 저장할 수 있습니다.
자료를 선택하지 않으면 프로젝트 전체에 질문하며, 일부만 선택하면 그 자료에 한정합니다.
자료 관리에는 다시 읽기, 작업 상태, 기존 자료함 연결과 업로드 등 부가 기능을 모았습니다.
개인용 로컬 앱은 PC 자료를 직접 읽습니다. 공유 시연 사이트에서는 시연 자료를 사용하며,
방문자의 PC 폴더를 서버가 직접 읽을 수 없습니다. 공개 업로드는 명시적인 동의가 필요합니다.

3. 동봉 예제로 바로 확인하기
프로젝트 이름을 [합성] 교육 준비로 만듭니다.
폴더 추가에서 service/sample_data/notebook-v80/교육 자료를 선택합니다.
파일 추가에서 service/sample_data/notebook-v80/취합 확인사항.md를 선택합니다.
세 파일의 읽기가 끝나면 아래 질문을 차례로 해 보세요.
- 미회신 부서는 어디인가요? → 회계과, 회신 현황.txt의 3행 원문을 확인합니다.
- 핵심 내용을 요약해줘
- 일정과 할 일을 알려줘
- 자료를 비교해줘
- 보고서 초안을 작성해줘
자료 예제는 가상의 교육이며 법령이나 기관 지침이 아닙니다. 자동으로 공식 규정으로 등록되지 않습니다.
답변 아래 파일명·위치를 눌러 발췌문과 원본을 확인하세요.
답변 방식·확인 범위를 펼치면 AI 사용 여부와 읽지 못한 부분을 확인할 수 있습니다.
초안은 수정·복사·TXT 저장할 수 있습니다. 프로젝트를 다시 열면 자료와 대화가 이어집니다.
스캔 이미지 PDF, 구형 HWP 등 읽지 못하는 형식은 본문을 확보한 것으로 취급하지 않습니다.

4. AI 없이 사용 / Upstage 연결 / 로컬 모델
최초 선택은 upstage이며 키가 없으면 원문 검색으로 안내합니다. offline에서 이 모델 사용을 누르면 프로젝트 질문과 일반 채팅을 포함한 모든 AI 사용을 끕니다.
AI 설정에서 프로필이 허용되어 있어도 채팅의 AI 사용 체크를 끄면 채팅에는 AI를 사용하지 않습니다.
서무 안내에서도 AI 보조 사용을 끄면 등록 근거와 정형 안내를 사용합니다.
자료에 없는 정보는 임의로 채우지 않습니다. AI 없는 요약·비교·초안은 자료 발췌와 정해진 구성으로 작성되므로 담당자 검토가 필요합니다.

Upstage Solar Pro4는 기본 활성 프로필로 설정되어 있으나 API 키는 포함하지 않습니다.
B안 데스크톱 업무 설정 → AI 모델 설정에서 Upstage 연결 주소 https://api.upstage.ai/v1,
모델명 solar-pro4를 확인하고, 고급 설정의 비밀번호 입력란에 발급받은 API 키를 입력하세요.
연결값 저장을 누른 다음 실제 응답 확인을 실행합니다. 키는 서버 설정에만 저장되며 배포 파일이나 채팅에 넣지 마세요.
프로젝트 질문과 검색된 자료 발췌문은 답변 생성을 위해 Upstage로 전송됩니다. 민감 자료를 연결하기 전에 기관의 사용 기준을 확인하세요.

로컬 모델은 별도 설치가 필요하며 모델 가중치는 동봉하지 않습니다.
Ollama를 설치하고 gemma3:4b 또는 llama3.2:3b 가중치를 각각 준비한 뒤,
연결 주소 http://127.0.0.1:11434/v1에서 모델 프로필 local_gemma 또는 local_llama를 별도로 연결합니다.
모델을 바꿔도 같은 원문·본문 색인을 검색합니다. 자료 등록은 모델 학습이 아닙니다.

5. 동봉 자료와 보관
검토된 공통 자료 123건(법령·지침 발췌 117건, e-사람 PDF 6개·총 221쪽)을 복원합니다.
123개 서로 다른 법령이라는 의미는 아닙니다. 복무제도 안내·FAQ와 기관 규정·서식 관리 기능도 포함합니다.
보관 원문은 오프라인에서 확인할 수 있고 공식 사이트의 최신 원문 조회에는 인터넷이 필요합니다.
이 릴리스는 법령 최신성이나 여비 계산 가능 기간을 새로 승인하지 않습니다.
개인 프로젝트·대화·소속·기관 비공개 자료·기존 설정·API 키는 배포본에 들어 있지 않습니다.
사용하면서 생성한 자료와 대화는 이 설치 폴더에 저장됩니다. 다른 PC로 자동 동기화되지 않습니다.
백업은 서버 종료 후 설치 폴더 전체를 복사하세요. 직접 연결한 원본 폴더도 별도로 보관해야 합니다.
원본을 다른 위치로 옮기면 새 위치를 프로젝트에 연결해야 합니다.

6. 제출 검증
검증 결과와 이번 검사의 범위는 docs/SUBMISSION-v81-VALIDATION.txt를 보세요.
별도 시험 설치에서 실행할 수 있는 프로젝트 검증 도구:
service\.venv\Scripts\python.exe service\tools\verify_notebook_submission.py --base http://127.0.0.1:8781 --output notebook-verification.json
이 도구는 합성 프로젝트·질문·초안을 생성합니다. 평소 업무 설치가 아닌 시험 설치에서 사용하세요.
실제 다른 물리 PC의 시험, 같은 PC의 새 폴더 설치 시험, 기존 서버 연결 결과는 구분해 기록합니다.
