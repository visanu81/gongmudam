공무담 v78 · 새 설치 검증 결과
확인일: 2026-10-26

이번 반영 내용
확인한 내 소속을 바탕으로 기관명·등록 키워드를 반복하지 않고 기관 규정·서식을 찾는다.
교육/연수, 참석/참여, 기한/언제까지, 서식/양식 등 상황 표현과 원문을 함께 확인한다.
후속 질문은 최근 업무를 이어가며, 이전 기한 질문을 서식의 필수 항목 질문에 강제하지 않는다.
다른 기관·신분을 명시하면 질문 범위를 우선한다. 이름이 겹치는 부모기관·교육청·의회를 구분한다.
무관한 주제, 미확인 소속, 초안·비활성·삭제 자료나 부적합한 기준일은 근거로 추정하지 않는다.
예산·회계, 복무·휴가, 출장·여비, 물품·계약, 교육·행사, 문서·기록, 보안·개인정보, 기타, 미분류로 관리한다.
분류 수정도 초안 → 비교 → 적용을 거치며 이전 분류·본문·서식과 변경 이력을 보존한다.
필터 변경 중 편집 내용 유지, 빈 분류 안내, 키보드 전환을 포함한다.

다른 PC를 위한 구성
공개 등록 근거 86건(법령·지침 발췌 80건, e-사람 PDF 6개·221쪽)과 복무 안내·FAQ 및 정형 답변 자료를 보존한다.
보관 원문·해시·쪽수 확인이며 이번 작업에서 법령 현행성이나 여비 계산 가능 기간을 갱신한 것은 아니다.
AI 없이 등록 자료의 원문 검색·발췌와 구조화된 안내를 제공한다. 별도의 모델 학습이나 Graphify 설치가 필요하지 않다.
기본 AI 설정은 offline이다. 로컬 모델 연결은 선택이며 모델 가중치·Python 설치 프로그램은 동봉하지 않는다.
이번 릴리스에서는 Gemma·Llama의 실제 재시험을 수행하지 않았다. 과거 모델 결과는 별도 v71 기록으로 구분한다.
개인 업무 DB·프로젝트·대화·소속·실제 기관 개정 기록·개인 설정은 배포하지 않는다.
합성 예제 TXT는 설치 시 자동 등록·적용하지 않으며 별도 시험 설치에서 사용한다.

설치와 검증 환경
같은 Windows PC의 한글·공백을 포함한 새 경로에 후보 ZIP을 풀어 새 venv와 DB로 설치했다.
install.bat에서 --no-index와 동봉 wheel 24개만 사용했고 pip check가 통과했다.
실행기는 run.bat과 동일한 tools/run_local_app.py를 --port 8898 --no-browser로 호출했다.
실제 두 번째 물리 PC에서 실행한 결과는 아니다.
검증 중 발견한 보완을 설치본에 동기화해 다시 검사했으며 최종 ZIP의 실행 자산은 이 설치본과 해시로 대조한다.

설치본 최종 자동검사
서비스 Python 910개, 통합 Python 19개, 데스크톱 JS 36개, 서비스 JS 37개,
기관 디렉터리 Python 8개: 총 1,010개 통과.
공개 터널·공개 런처 등 개인용 패키지에 포함하지 않는 별도 배포 도구의 검사는 이 수치에 포함하지 않는다.
로그의 모델 오류·손상 PDF 문구는 모형 응답/손상 자료 처리 테스트의 예상 로그이며 실제 모델 실패로 집계하지 않는다.

실제 API 질문·기관 자료 처리 검증
18개 질문을 포함한 34개 항목 통과, 실제 모델 호출 0회.
- 처음 설치한 offline 설정, 등록 자료 86개와 매뉴얼 6개·221쪽, 설치 폴더 내부 원문 경로.
- 동봉 TXT 원문 업로드 → 초안 제외 → 비교·적용 후 AI 없는 자연어 질문으로 3일 전 확인.
- 등록 키워드와 다른 표현, 관련 서식 링크, 이어지는 양식·필수 항목 질문.
- v2 초안을 저장만 하면 3일 전 유지, 비교·적용 후 5일 전으로 변경.
- 분류 초안은 적용 분류 유지, 적용 후에만 분류 변경, 이전 버전 원문·분류 보존.
- 소속 미확인·다른 기관·무관한 교육 저작권 질문에 기관 자료를 대신 답하지 않음.
- 부산광역시와 부산광역시교육청 구분, 미등록 부산광역시의회를 부모기관으로 처리하지 않음.
- 가족돌봄·건강검진·공용차량 출장·사무용품 예산의 공통 자료 재조회.
- 인용문·원문·버전·SHA-256 일치, 원본 예제·설정 파일 불변, 합성 문서 최종 비활성.
이는 자료 검색과 출처 연결을 검증한 것으로 모든 질문의 법적 해석·개인별 적용을 자동 승인하는 결과가 아니다.

이번 새 설치에서 발견해 보완한 사항
TXT 원문의 기한 안내와 서식 안내가 별도 추출 단위일 때 서식 링크가 빠졌다.
같은 현재 적용본의 인접 문단에 명시된 서식 선언만 확인하도록 보완했다.
멀리 떨어진 다른 절을 검색해 임의 연결하지 않으며 예산·금액 질문에서 인접 검수 서식을 연결하지 않는다.
공식 법령 근거를 기관 자료용 인접 문단 처리에 넘기지 않는 방어 조건도 확인했다.
동일 본문 재업로드가 올바르게 거부되는 경우에는 검증 예제를 실제 변경 본문으로 수정했다.

검증용 DB·venv와 브라우저 소속 정보는 ZIP에 포함하지 않는다.

기존 v77 ZIP은 보존했다. 실제 사용하는 서버와 공개 시연 배포·터널은 이 검증 서버와 구분한다.
