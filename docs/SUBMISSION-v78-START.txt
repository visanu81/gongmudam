공무담 v78 · 첫 실행 안내

설치하고 실행하기
1. ZIP 파일을 Windows PC의 새 폴더에 전부 풉니다. 압축 파일 안에서 실행하지 마세요.
2. Windows Python 3.12 x64를 설치합니다. Python Launcher와 Tcl/Tk를 포함하세요. 파일·폴더 선택 창에 Tcl/Tk가 필요합니다. 확인 명령은 `py -3.12 --version`입니다.
3. 압축을 푼 공무담 폴더에서 `1_설치.bat`을 실행합니다. 포함된 오프라인 wheel로 설치합니다.
4. `2_공무담_실행.bat`을 실행하면 B안 데스크톱 화면이 브라우저에서 열립니다. 기본 주소는 `http://localhost:8781/desktop/?variant=B`입니다. 다른 포트는 `run.bat --port 8787`처럼 지정할 수 있습니다. 서버가 실행되는 콘솔 창은 열어 두세요. 종료하려면 실행 창에서 Ctrl+C를 누릅니다.

기관 자료 예제 준비
1. B안 화면 아래쪽의 `소속 설정`을 열고 기관을 `합성 제출검증기관`, 신분을 `국가공무원`, 지역을 `서울특별시`로 설정합니다.
2. `서무 안내 > 자료·업무 설정 > 기관 자료 관리`로 이동해 기관 지침을 등록합니다.
   - 제목: `[합성 예제] 연수 참가 접수 안내`
   - 분류: `교육·행사`, 키워드: `연수 신청 접수`, 시행일: `2026-01-01`
   - 원문 파일: `service/sample_data/institution-rules-v78/연수_참가_접수_v1.txt`
   저장한 초안을 비교하고 적용합니다.
3. 같은 기관에 서식을 등록합니다.
   - 제목: `[합성 예제] 교육참가 신청서`
   - 종류: `서식`, 분류: `교육·행사`, 키워드: `교육참가 신청서`
   - 원문 파일: `service/sample_data/institution-rules-v78/교육참가_신청서.txt`
   저장한 초안을 비교하고 적용합니다.

AI를 끄고 질문하기
AI 설정은 기본적으로 꺼져 있습니다. 이 예제를 확인하는 데 모델 가중치가 필요하지 않습니다.

1. `교육에 참여하려는데 언제까지 내야 해요?`라고 질문합니다. 기대 동작은 적용된 안내의 교육 시작 3일 전 마감과 신청서 원문을 연결해 보여주는 것입니다.
2. 이어서 `그럼 어떤 양식을 쓰면 돼요?`, `그럼 어떤 항목을 적어야 하나요?`라고 물어봅니다. 기대 동작은 신청서 이름과 원문의 필수 항목(부서, 성명, 연락처)을 인용하는 것입니다.
3. 같은 지침에 `연수_참가_접수_v2.txt`를 새 버전 초안으로 등록합니다. v2에는 교육 시작 5일 전이라는 변경 내용이 있습니다. 저장만 한 상태에서는 앞선 질문의 결과가 계속 v1의 3일 전이어야 합니다. 비교 후 적용하면 5일 전으로 바뀝니다.
4. 관리 화면에서 `교육·행사` 분류 필터와 버전 이력을 확인합니다. 분류를 바꿀 때도 변경을 저장한 뒤 버전을 비교하고 적용합니다. 적용 후에도 이전 분류와 원문 버전은 이력에 보존됩니다.
5. v1을 적용한 상태에서 아직 자료가 없는 다른 기관이나 주제를 물으면 그 합성 자료로 대신 답하지 않고 확인·등록 안내를 기대합니다. 기관별 자료가 필요한 질문에 소속을 설정하지 않았다면 소속 확인 안내를 기대합니다. 공개 공통 자료를 이용하는 질문은 소속 미설정 상태에서도 할 수 있습니다.

별도 검증 실행
패키지를 새로 설치한 별도 시험 폴더에서만 다음 명령을 실행하세요. 합성 문서를 생성하고 마지막에는 비활성 상태로 둡니다. 평소 사용하는 설치 폴더에서는 실행하지 마세요.

```bat
service\.venv\Scripts\python.exe service\tools\verify_institution_context_submission.py --base http://127.0.0.1:8781 --output context-verification.json
```

검증 결과와 범위는 패키지의 docs/SUBMISSION-v78-VALIDATION.txt를 참고하세요.

예제 자료 세 개는 설명을 위한 가상 원문이며 실제 기관의 규정, 정책 또는 법률 자문이 아닙니다. 예제 파일은 설치 시 자동 등록·적용되지 않습니다. 기관 자료 버전은 로컬 데이터에 보관되며 모델 학습이나 PC 간 자동 동기화를 하지 않습니다. 원문은 변경 없이 보관합니다. PDF·DOCX·XLSX·HWPX·TXT·MD·CSV는 본문 텍스트를 읽는 용도이며, 바이너리 원본의 레이아웃을 편집하지 않습니다.

공개 공통 자료는 86건(법령 발췌 80건과 e-사람 매뉴얼 PDF 6개·221쪽)입니다. 이는 보관된 스냅샷으로, 이번 자료나 실행 안내가 법령 현행성을 갱신했다는 뜻은 아닙니다.

로컬 AI는 선택 기능이며 AI 설정은 기본적으로 꺼져 있습니다. 모델 가중치는 패키지에 포함되지 않으며, 모델을 사용하려면 별도로 준비해야 합니다. 이번 안내 작성 과정에서 두 모델의 실제 재시험을 수행한 것은 아닙니다.

백업할 때는 서버를 먼저 종료하고 공무담 설치 폴더 전체를 복사하세요. 새 PC에 설치해도 기존 PC의 업무·대화·기관 자료가 자동으로 동기화되지 않습니다. 기존 설치 폴더를 덮어쓰지 말고 새 폴더에 설치하세요.
