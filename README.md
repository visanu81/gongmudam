# 공무담

공무원의 서무 업무를 돕는 도구입니다. 질문하면 결론부터 답하고, 적용 조건과 예외, 처리 순서, 기한, 서식, 원문 근거를 함께 보여 줍니다.

## 접속 주소

**<https://gongmudam.visanu81.workers.dev>**

설치 없이 브라우저로 바로 쓸 수 있습니다. 모든 방문자가 같은 공개 시연을 함께 보므로 실제 개인정보나 업무자료는 입력하지 마세요.

## 주요 기능

바탕화면 형태의 화면에서 아이콘을 눌러 업무 창을 엽니다.

| 기능 | 내용 |
|---|---|
| 서무 안내 | 복무·보수·여비·계약·회계 질문에 결론과 근거 조문으로 답합니다. 근거 버튼을 누르면 원문이 펼쳐집니다. 소속이나 사유가 부족하면 먼저 되묻고, 답한 말을 앞 질문에 이어서 읽습니다. |
| 출장정산 | 출장 사례를 입력해 여비를 계산하고 정산 서류 묶음을 만듭니다. |
| 자료 취합 | 부서별 자료 요청과 회신을 모아 정리합니다. |
| 업무자료 정리 | 폴더째 넣은 한글·PDF·엑셀 문서를 읽어 찾고 질문할 수 있게 합니다. |
| 업무 달력 | 오늘 할 일과 이번 주 마감을 보여 줍니다. |
| 업무도구함 | 계산기, 메모장, 문서 변환 같은 작은 도구를 모았습니다. |
| 변경 알림함 | 등록한 자료의 변경을 찾아 알립니다. 담당자가 검토한 뒤 반영합니다. |

## 사용 방법

1. 접속 주소를 열고 **서무 안내**를 누릅니다.
2. `연가 며칠이야?`처럼 질문합니다.
3. 맨 위의 결론을 읽고, 근거 버튼으로 원문을 확인합니다.
4. 되묻는 말이 나오면 대화창에 답합니다. 예: `국가공무원이에요`

`소속 설정`에서 소속을 정하면 그 기준으로 답합니다. AI 보조 칸을 끄면 AI 없이 등록 자료만으로 답합니다.

## 내 PC에서 실행

Windows와 Python 3.12 x64가 필요합니다. 필요한 패키지는 `service/wheels`에 들어 있어 인터넷 없이 설치됩니다.

1. `install-service.bat`을 실행합니다.
2. `run-gongmudam.bat`을 실행합니다.
3. 브라우저에서 <http://127.0.0.1:8892/>를 엽니다.

기본은 AI를 쓰지 않습니다. 개인 데이터베이스, 사용자 설정, 모델 가중치는 저장소에 없습니다.

## 구조

| 폴더 | 내용 |
|---|---|
| `desktop/` | 바탕화면 화면 |
| `service/` | 업무 기능 서버(FastAPI), 공개 원문 자료, 시험 |
| `integration/` | 화면과 서버 연결 |
| `cloudflare/` | 공개 시연 배포(Workers, Container) |
| `tools/` | 배포본 준비와 답변 비교 도구 |

- **AI 모델:** 공개 시연의 기본은 Upstage `solar-pro4`입니다. 특정 모델에 묶이지 않으며, 내 PC에서는 Ollama 모델로 바꿀 수 있습니다. 모델이 없거나 응답이 맞지 않아도 등록 자료로 답합니다.
- **자료:** 공개 사이트에는 공개 법령·지침과 합성 사례만 씁니다. 원문 사본과 해시를 함께 보관합니다.
- **비밀값:** API 키는 저장소에 넣지 않습니다. 공개 시연의 키는 배포 환경의 비밀값으로 둡니다.

## 보안 검사

공공 GitLab의 필수 검사(Gitleaks, Semgrep, OSV-Scanner, Trivy, Syft)를 통과하도록 관리합니다. `.gitleaks.toml`은 `service/submission-manifest.json` 한 파일만 제외합니다. 이 파일의 값은 파일 해시이며 비밀값이 아닙니다.
